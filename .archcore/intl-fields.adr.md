---
title: "Локаль, числовое поле и поле времени"
status: accepted
---

## Context

Волна 5a (2026-09-25) закрывает числовые поля и время из состава 1.0 и требование плана
«локализованные числа и даты с первого стабильного релиза». Решения интервью: локаль
приходит из конфигурации кита, форматирование и разбор строятся только на `Intl` без
внешних библиотек, модели остаются простыми и без часового пояса. Даты волны 5b стоят на тех
же примитивах.

## Decision

- Локаль живёт в контексте `LOCALE_KEY`: `createNuiConfig({ locale })` и
  `provideNuiConfig({ locale })` провайдят её (компонента-провайдера нет), `useLocale(explicit?)` берёт явное значение, затем
  ближайший провайдер, затем `en-US`. `navigator.language` не читается: сервер и клиент
  форматируют одинаково, локаль запроса передаётся явно. Сегодняшняя дата через конфиг не
  инжектируется (2026-09-25: `useToday`/`TODAY_KEY` удалены как API без потребителя):
  календарь возьмёт локальную дату и получит проп `today` для тестов и «бизнес-даты», а
  метку «сегодня» отрисует после mount, чтобы SSR не зависел от часового пояса сервера.
- Intl-хелперы — чистые функции в `packages/primitives/src/intl`: `numberSymbols`
  (разделители, минус, цифры и литералы из `formatToParts`), `formatNumber`, `parseNumber`
  (bidi-метки, локальные цифры, минус в любой форме, скобки, проценты), `withStepPrecision`,
  `snapToStep`/`stepNumber` на целочисленной арифметике; `parseTime`/`formatTimeModel`,
  `timeOptions`, `formatTimeLabel`, `timeLayout` (порядок сегментов и литералы из
  `formatToParts`, периоды, цифры), `enterDigit` с автопереходом, `stepSegment` с переносом,
  `segmentLabels` через `Intl.DisplayNames` с английским фолбэком. Форматтеры кэшируются.
- `NuiNumberField`: единственный доступный элемент — `<input role="spinbutton"
  inputmode="decimal">`, степперы — кнопки в обёртке `aria-hidden` с `tabindex="-1"` и
  отменённым `pointerdown`, чтобы фокус не уходил из поля. Пока поле в фокусе, текст —
  черновик; коммит по blur и Enter разбирает, зажимает в `min`/`max` и форматирует, модель
  равна разбору отформатированного текста. Клавиши ↑/↓, Shift, PageUp/PageDown, Home/End
  идут через `stepNumber` от разобранного черновика; внешние изменения модели переписывают
  текст только когда он им не соответствует.
- `NuiTimeField`: сегменты — нативные `<input role="spinbutton">`, ввод перехватывается на
  `beforeinput` и раздаётся посимвольно, а не разбирается из `value`; `useTimeDraft` держит
  черновик по сегментам и пишет модель только когда все сегменты заполнены, иначе `null`;
  зажим в `min`/`max` происходит при уходе фокуса, чтобы не ломать ввод посреди числа; ряд
  сегментов принудительно LTR (`direction: ltr; unicode-bidi: isolate`, `rtl: false` у
  навигации); id поля стоит на сегменте часов, статический `tabindex="0"` — на первом
  сегменте в DOM; подсказки — `NuiListbox` в нативном `popover="auto"` с `useFloating`, как у
  select. Символы одного события ввода маршрутизируются в текущий сегмент с переходом
  (`flow`), поэтому вставка `0930` растекается по сегментам.
- Playground держит секцию «Числа и время» с переключателем локали на `NuiSelect`, который
  передаёт `locale` каждому полю; e2e проверяет формат по blur, шаги, смену локали, ввод по
  сегментам, подсказки, LTR в RTL, плотность и axe.
- Отступы полей отделены от отступов кнопок: `--nui-field-padding-sm/md/lg` (10/12/16px,
  compact 8/10/12px) для input, textarea, select, combobox, числового поля и поля времени;
  `--nui-control-padding-*` остаются кнопкам и вкладкам. Клик по пустому месту поля времени
  (`pointerdown` вне сегментов, кнопки и списка) фокусирует первый незаполненный сегмент,
  иначе часы.
- Маска ввода — чистый `applyMask(text, mask)` в `packages/primitives/src/mask` (`#` цифра,
  `A` буква, `*` буква или цифра, `\` экранирует литерал) плюс `maskCaret` для позиции курсора;
  `NuiInput mask` форматирует текст на `input`, Backspace перед литералом удаляет символ
  перед ним, модификатор `v-model.unmasked` отдаёт в модель только значимые символы.

## Alternatives Considered

- `<input type="number">`: браузеры по-разному обращаются с локалями и не дают валюту,
  проценты и локальные цифры.
- `navigator.language` по умолчанию: расхождение SSR и клиента при гидратации.
- Одно текстовое поле с маской для времени: хуже клавиатура и озвучивание, нет границ
  сегментов для AT.
- Сторонние библиотеки форматирования: `Intl` покрывает задачу без зависимостей.

## Consequences

Даты (5b) переиспользуют `useLocale`, `parseTime`/`formatTimeModel` и сам
`NuiTimeField` под календарём при `time`. Проверка: харнесы `locale`, чистые тесты
`intl-number`/`intl-time`, драйверы `number-field`/`time-field`, SSR-сценарии, e2e
`tests/e2e/intl.spec.ts` с axe в light/dark.
