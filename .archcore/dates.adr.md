## Context

Волна 5b (2026-09-25) закрывает даты из состава 1.0: календарь, выбор даты, даты со
временем и периода. План требует локализованные даты с первого релиза, SSR-детерминизм,
клавиатуру по WAI-ARIA и переиспользование локали, поля времени и слоёв из 5a/3b.

## Decision

- Модель — строки без часового пояса: дата `YYYY-MM-DD`, набор `string[]`, диапазон
  `{ start, end }`, дата со временем `YYYY-MM-DDTHH:mm`. Вся арифметика в
  `packages/primitives/src/date` идёт через `Date.UTC`/`getUTC*` и `timeZone: 'UTC'` в
  `Intl`, поэтому переходы на летнее время и пояс сервера день не сдвигают; только
  `localToday()` читает локальные компоненты часов.
- Начало недели берётся из `Intl.Locale#getWeekInfo`/`weekInfo`, а без них — из таблицы
  регионов CLDR (`weekStartOfRegion`); тест сверяет таблицу с ICU на Node. Подписи дней,
  месяцев и дат — `Intl.DateTimeFormat`, цифры — `formatNumber` из 5a.
- Текст даты в пикерах — числовой шаблон локали из `formatToParts` (`datePatternOf`), с
  четырёхзначным годом; парсер принимает локальные цифры и ISO, отбрасывает bidi-метки и
  двузначный год, частичный ввод оставляет модель нетронутой, невалидный текст откатывается
  на blur.
- Одна `NuiCalendar` с `mode: single | multiple | range` и одним `v-model`
  (`NuiCalendarValue`) вместо generic-дискриминанта: запись в `Ref` потребовала бы `as`.
  Месяц — `v-model:month` с внутренним fallback; `today` — проп, без него локальная дата
  после `mounted`, чтобы серверная разметка не зависела от часов сервера (провайдер `today`
  в конфиге отвергнут как API без потребителя, см. intl-fields).
- Разметка: `section` на месяц, `table role="grid"`, дни — `button` внутри `gridcell` с
  `time[datetime]`, полной датой в `aria-label`, `aria-selected`, `aria-disabled` и
  `aria-current="date"`. Фокус — roving tab stop (`focused`), `request(date)` зажимает в
  `[min, max]`, сдвигает показанные месяцы и фокусирует кнопку post-flush по `time[datetime]`.
  Закрытые даты фокусируемы, но не выбираются.
- Клавиатура: `gridMoveFor`/`gridTargetDate` (стрелки, Home/End, PageUp/PageDown, Shift —
  год, RTL меняет горизонтальные стрелки местами); сетки месяцев и лет —
  `cellMoveFor`/`cellTargetIndex` по 3 колонкам, Escape возвращает дни.
- Выбор диапазона: клик-клик с нормализацией порядка, превью по `hovered`, протягивание
  через `pointerdown`/`pointerup` с «взведённым» днём, который переживает `pointerup` на том
  же дне и гасится последующим `click`, иначе одиночный клик закрывал бы диапазон сам на
  себя. Пресеты — `{ label, range | (today) => range }` с `aria-pressed`.
- Анимация смены месяца — перемонтирование сетки по `:key` с одноразовым `@keyframes`
  (`--_slide`, инверсия в RTL), без `<Transition>`. Контейнер-запросы для скрытия вторых
  месяцев отвергнуты: `container-type: inline-size` лишает поповер собственной ширины;
  месяцы переносятся `flex-wrap`, а число месяцев задаёт потребитель.
- Пикеры: общий каркас `NuiDateField` (поле, кнопки очистки и календаря, панель
  `role="dialog" aria-modal="false"` в `popover="manual"` с `useFloating`), обвязка —
  `usePickerPopover` (показ, скрытие с возвратом фокуса, закрытие по `focusout` наружу и
  Escape). `NuiDatePicker` открывается кнопкой или ArrowDown, выбор дня закрывает диалог;
  с `time` под календарём стоит `NuiTimeField`, текст поля — `дата HH:mm`, выбор дня
  диалог не закрывает, Enter во времени — закрывает. `NuiDateRangePicker` — два поля в
  одной рамке (id поля на начале, `endLabel` на конце), два месяца, пресеты, закрытие после
  второго конца или пресета.
- Playground держит секцию «Даты» (инлайн-календари и три пикера), e2e проверяет клик,
  клавиатуру, сетки месяцев, ввод текста, открытие и возврат фокуса, диапазон, превью,
  драг, RTL и axe.

## Alternatives Considered

- `Date`-объекты в модели: тянут часовой пояс и сериализацию, ломают SSR-детерминизм.
- `dateStyle: 'short'` для текста поля: даёт двузначный год в части локалей.
- Provider-компоненты или конфиг `today`: отвергнуты пользователем как React-изм и как API
  без потребителя.
- Контейнер-запросы для адаптивных месяцев: см. решение выше.

## Consequences

Даты используют `useLocale`, `NuiTimeField`, `usePopover`/`useFloating` и общие иконки
(`calendar`). Дальнейшее: upload (5c) и layout/sidebar (5d); `useMediaQuery` из 5d позволит
пикерам самостоятельно переключаться на один месяц на узких экранах.
