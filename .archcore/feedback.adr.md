## Context

Волна 2b закрывает группу плана «обратная связь и слои». Уведомления требуют
императивного API, очереди с таймерами, озвучивания и корректного поведения рядом с
модальными диалогами; остальные компоненты статичны. Решения согласованы 2026-09-23.

## Decision

- `useToast()` — императивный сервис над store из `@numior/primitives`
  (`createToastStore`: очередь, таймеры с паузой/возобновлением, состояние `leaving` на
  время `exitDuration`, опциональный `limit`, без таймеров на сервере). `createNuiConfig()`
  создаёт store на приложение; `provideNuiConfig({ toasts })` — на поддерево; без плагина
  на клиенте используется общий store, на сервере — всегда свежий.
- `NuiToaster` — всегда открытый `popover="manual"` с `role="region"` и
  `aria-live="polite"`: live-регион существует до появления первого уведомления, поэтому
  озвучивается надёжно и остаётся в top layer. При показе уведомления во время открытого
  модального диалога регион поднимается через `raise()` (`hidePopover` + `showPopover`), но
  по спецификации остаётся инертным до закрытия диалога; это документированное ограничение.
- Дефолты: все тоны автозакрываются через 5000 мс (`duration: 0` — до закрытия
  пользователем), позиция `top-end`, лимита видимых нет. Таймер ставится на паузу при
  наведении, фокусе внутри и скрытой вкладке — уход указателя возобновляет таймеры только
  без фокуса внутри, а уход фокуса только без наведения (аудит 2026-09-28); Esc закрывает сфокусированное уведомление и
  переводит фокус на соседнее; уведомления не забирают фокус при появлении. `error`
  дополнительно несёт `role="alert"`.
- Стопка: регион рендерит уведомления новыми вперёд, каждое внутри `nui-toaster__item`.
  В свёрнутом состоянии верхняя карточка целиком, две предыдущие выглядывают из-под неё
  уменьшенными (`--_index`, `--_peek`, `scale`), остальные скрыты; наведение, фокус внутри
  или `expand` раскрывают список с зазором. Высоты карточек измеряет `ResizeObserver`
  региона (переменные `--_size`, `--_offset`, `--_front-size`), а состояния и движение —
  только CSS (`:hover`, `:focus-within`, `@starting-style`, `--nui-duration-slow`).
  Таймеры всех видимых уведомлений останавливаются, пока стопка раскрыта. Слот вызывается
  на каждое уведомление с `{ toast, dismiss }` внутри элемента стопки; `NuiToast`
  экспортируется как часть.
- Кнопки только с иконкой (закрытие уведомления, алерта, диалога) квадратные: иконка
  приходит пропом `icon`, и `NuiButton` без текста становится квадратным сам; глиф
  выравнивается по первой строке текста и по краю отступа.
- `NuiAlert`: `variant` (soft/outline/solid) × `tone`, иконка тона из реестра,
  `closable` с `v-model:open`, `role="alert"` только для `error`.
- `NuiProgress` — нативный `<progress>` с вендорными псевдоэлементами по одному правилу на
  движок; indeterminate — сплошной сегмент 40 % поверх трека, который полностью выходит за
  оба края (`background-position` −67 % → 167 %), поэтому цикл без шва; под reduced motion
  замедляется вдвое.
- `NuiSkeleton` — декоративный (`aria-hidden`); блик занимает 30 % полосы и проходит её за
  2 с (150 % → −50 %), под reduced motion анимация отключается
  полностью: это исключение из правила «замедлять, не убирать», допустимое для чисто
  декоративного мерцания.
- Реестр иконок получает алиасы `info`, `success`, `warning`, `error` (Lucide `info`,
  `circle-check`, `triangle-alert`, `circle-x`, загрузка по требованию).

## Alternatives Considered

- Только декларативный `<NuiToast v-model:open>`: не покрывает уведомления из stores и
  обработчиков ошибок.
- Регион, открываемый при первом уведомлении: live-регион, появляющийся вместе с
  содержимым, не озвучивается стабильно.
- Teleport-регион с `z-index`: перекрывается top layer и требует пробрасывать тему.
- Кастомный `<div role="progressbar">`: теряет нативную семантику ради стилей, которые
  и так достижимы через псевдоэлементы.

## Consequences

Один `<NuiToaster>` на приложение; при нескольких регионах они делят store. В jsdom нет
Popover API, поэтому поведение региона проверяется e2e (порядок отрисовки над диалогом,
автозакрытие, пауза, Esc, позиции и RTL, axe), а юнит-тесты держат контракт через стабы.
Следующие волны: навигация (tabs, breadcrumbs, pagination, menu) и select/combobox на тех
же слоях.
