# @numior/forms

Vue 3 forms with built-in and async rules, server errors and Standard Schema validators such as Zod, Valibot and ArkType.

Part of [Numior UI](https://ui.numior.ru/en/), a UI kit for Vue 3.5+ and Tailwind CSS 4.

Until 1.0 the packages ship as `1.0.0-alpha.N`, and the API still changes between them.

## Install

```sh
pnpm add @numior/forms
```

An app usually installs [`@numior/kit`](https://www.npmjs.com/package/@numior/kit), which brings this package along.
