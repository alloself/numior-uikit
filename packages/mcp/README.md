# @numior/mcp

MCP server with the Numior UI reference for AI assistants: components, docs pages, examples, tokens and icons.

Part of [Numior UI](https://ui.numior.ru/en/), a UI kit for Vue 3.5+ and Tailwind CSS 4.

Until 1.0 the packages ship as `1.0.0-alpha.N`, and the API still changes between them.

## Use

An MCP client starts the server over standard input:

```sh
claude mcp add numior -- npx -y @numior/mcp
```
