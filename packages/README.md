# Packages

Работающие пакеты основания:

| Пакет                | Назначение                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@numior/tokens`     | CSS-токены, light/dark/system, semantic roles, плотность, типографика и цвета подсветки кода; `accents.css` — пресеты акцента через `data-nui-accent`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `@numior/primitives` | Headless-поведение: контекст поля и черновики контролов (`provideDraftCommits`), checked state, radio-группа, реестр иконок, слои (`useFloating`, `usePopover`, `useDialog`), списки (`useListNavigation`, `useVirtualList`, `useReorder`), загрузка файлов (`validateFiles`, `useFileDrop`, `useUploadQueue`), медиазапросы (`useMediaQuery`), буфер обмена (`useClipboard`), горячие клавиши (`useHotkey`), наблюдение за прокруткой (`useScrollSpy`), локаль (`useLocale`), словарь текстов (`useMessages`, `plural`), Intl-хелперы чисел, времени и дат (ISO-модель, арифметика, сетка месяца, недели, локальный текст), цветовая схема |
| `@numior/vue`        | Стилизованные компоненты `Nui*`, Vue 3.5 peer, отдельные CSS и декларации                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `@numior/forms`      | Формы: `NuiForm`, `NuiFormField`, `NuiFieldArray`, `NuiSmartForm` с `formConfig` и ядро на собственном движке `FormEngine` (`useForm`, `useField`, `useFieldArray`, Standard Schema, встроенные и асинхронные правила, скрытые поля, серверные ошибки `NuiFormError`, время проверки и отправка), сменное хранилище через `FormEngineFactory`, отдельные CSS                                                                                                                                                                                                                                                                                |
| `@numior/tailwind`   | Пресет Tailwind 4: токены на стандартных именах (`bg-surface`, `rounded-md`, `text-sm`), утилиты `grid-auto`, `bg-dots`; проза `.nui-prose` живёт в `@numior/tokens/prose.css`                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

`@numior/primitives` зависит только от Vue и не содержит CSS и визуальных решений;
`@numior/vue` потребляет его и добавляет стили. `@numior/forms` строится на `@numior/vue` и
`@numior/primitives`, а `@numior/vue` от форм не зависит; решение о собственном ядре форм записано в [ADR форм](../.archcore/forms.adr.md). Будущие
независимые пакеты из принятого плана: `grid`, `spreadsheet`, `editor-core`, `editor-vue`,
`content`, `collaboration`, `offline`, `nuxt`, `cli`. Они ещё не реализованы. Их манифесты и API появятся вместе с первым
рабочим кодом, а не как пустые publishable пакеты.

Все текущие workspace приватные. CSS подключается явно; исходники доступны
внутренним инструментам через условие `@numior/source`. Обычный импорт использует
собранный `dist`; не импортируйте чужой `src` по относительному пути.
