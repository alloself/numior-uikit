`@numior/primitives` зависит только от Vue и не содержит CSS и визуальных решений;
`@numior/vue` потребляет его и добавляет стили. `@numior/forms` строится на `@numior/vue` и
`@numior/primitives`, а `@numior/vue` от форм не зависит; `@numior/nuxt` держит `@numior/vue`, `@numior/tokens` и `@numior/primitives` как peer, `@numior/forms` и `@numior/table` — необязательные peer; решение о собственном ядре форм записано в [ADR форм](../.archcore/forms.adr.md). Будущие
независимые пакеты из принятого плана: `collaboration`, `offline`, `cli`. Они ещё не реализованы; лист `@numior/spreadsheet` растёт по [ADR листа](../.archcore/spreadsheet.adr.md), таблица `@numior/table` описана в
[ADR таблицы](../.archcore/table.adr.md), ядро редактора `@numior/editor-core`, `@numior/content` и `@numior/editor-vue` — в
[ADR редактора](../.archcore/editor.adr.md). Их манифесты и API появятся вместе с первым
рабочим кодом, а не как пустые publishable пакеты.

Все текущие workspace приватные. CSS подключается явно; исходники доступны
внутренним инструментам через условие `@numior/source`. Обычный импорт использует
собранный `dist`; не импортируйте чужой `src` по относительному пути.
