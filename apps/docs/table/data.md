# Данные

Таблица сортирует и фильтрует строки в браузере, а с `source` поручает это серверу.

Значение ячейки возвращает `column.value(row)`. Числа и даты сортируются по величине, строки — по
алфавиту текущего языка, а пустые значения `null` идут в конец.

На больших данных сортировка, фильтры и группировка считаются частями и показывают прогресс.
Когда расчёт закончен, приходит событие `settle` с числом строк.

Флажок «все» выбирает строки, видимые после фильтров. Свойство `loading` показывает заглушки
вместо строк, а пустые `rows` — [Empty](/components/empty) или слот `empty`.

## Фильтры и итоги

Фильтр в меню колонки зависит от её типа: текст, число или дата. С `filter: 'set'` фильтр
предлагает выбрать значения из списка. Модель `v-model:quick` ищет текст сразу по всем
текстовым колонкам.

Длинный список показывает первые сто значений, остальные находит поиск над списком. «Выбрать все»
со снятой после этого галочкой даёт фильтр с `exclude: true`: он прячет названные значения, а
значения, которые появятся позже, остаются видны.

Пока значения собираются, список помечен как занятый, а если сбор дольше 120 мс, на месте
списка стоит «Загружаем значения…».

Колонка с `aggregate` добавляет внизу строку итогов, например сумму или среднее. В строке итогов
видны подпись `totalsLabel` и число строк, оставшихся после фильтров.

## Группы

Модель `v-model:groupBy` собирает строки в группы по значениям колонок, и итоги считаются для
каждой группы. Колонки можно объединить под общим заголовком, если описать группу как
`{ key, label, children }`.

## Дерево строк

Функция `getChildren` превращает таблицу в дерево: у строки с детьми появляется стрелка, а дети
стоят с отступом. Ключи раскрытых строк хранятся в `v-model:expanded`.

Если дети ещё не загружены, отметьте такую строку через `hasChildren`. При раскрытии таблица
пришлёт событие `load` и покажет детей, когда они появятся. Щелчок по стрелке раскрывает строку,
не перенося фокус и не выделяя ячейку.

Строка итогов дерева считает все строки, оставшиеся после фильтров, вместе со свёрнутыми. Родители
найденных строк остаются в дереве и тоже входят в итог.

## Подробности строки

Слот `detail` добавляет к строке стрелку, а раскрытая строка показывает под собой содержимое слота
на всю ширину таблицы. Ключи раскрытых строк хранятся в `v-model:expanded`, а `hasDetail`
оставляет стрелку только тем строкам, у которых есть подробности.

Стрелки на клавиатуре проходят через блок подробностей, а Tab переводит фокус внутрь него.
Щелчки, клавиши и вставка внутри блока достаются его содержимому, поэтому туда можно положить
вторую таблицу.

Выделение, копирование и правка ячеек пропускают блоки подробностей, и на странице остаётся
столько же строк. С `height` таблица учитывает высоту блока при прокрутке. В дереве строк
подробности не работают.

## Десять тысяч строк

С `height` таблица прокручивается внутри себя и рисует только видимые строки высотой `rowHeight`
и видимые колонки.

Колонка с `pin` не уезжает при горизонтальной прокрутке, а строки из `pinnedRows` стоят под
заголовком. Закрепить или скрыть колонку можно и в её меню.

<Example name="table/Windowed" />

С `rowHeight="auto"` высота каждой строки зависит от её содержимого, а таблица по-прежнему рисует
только видимые строки. Колонки с `wrap` переносят текст.

Таблица измеряет строки, когда они появляются на экране. Пока высота прокрутки уточняется, строка
под заголовком не сдвигается.

## Данные с сервера

Свойство `source` загружает строки с сервера. Функция `fetch({ offset, limit, sort, filters,
signal })` возвращает `{ rows, total }`, а если общее число неизвестно, — `{ rows, hasMore }`.

Таблица запрашивает строки блоками по `blockSize` по мере прокрутки и хранит пятьдесят последних
блоков. Пока блок загружается, на месте его строк видны заглушки.

Сортировка, фильтры и поиск выполняются на сервере, а устаревшие запросы отменяются через `signal`.
Функция `values` возвращает значения для фильтра-списка, а `totals` — строку итогов.

Без `height` таблица показывает данные постранично, по одному запросу на страницу. Метод
`refresh()` у ссылки на таблицу сбрасывает кеш, а ошибка запроса приходит событием `error`.
Выгрузка в CSV забирает весь результат по тысяче строк за запрос.

<Example name="table/Source" />

С `v-model:groupBy` группы считает сервер: `fetch` получает ключи `groupBy` и путь `groupPath` к
раскрытой группе. Пока путь короче списка ключей, верните `{ groups }` со значением, числом строк и
итогами каждой группы. На последнем уровне верните строки группы.

Группы сначала свёрнуты, а ключи раскрытых хранятся в `v-model:expanded`. Пока строки раскрытой
группы загружаются, на их месте видны заглушки.

<Example name="table/SourceGroups" />

Чтобы загружать с сервера дерево, задайте `source.children`: функция получает строку и
возвращает её детей. Строки с детьми отметьте через `hasChildren`, а дети загрузятся, когда строку
раскроют.

Пока дети загружаются, под строкой видна заглушка. Выгрузка в CSV у дерева берёт только строки
верхнего уровня.
