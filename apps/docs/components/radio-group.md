# Radio group

Выбор одного варианта из нескольких на виду.

<Example name="radio-group/Basic" />

Каждой `NuiRadio` задайте `value`, а выбранное значение читайте из `v-model` группы. Подпись,
подсказка и ошибка группы работают как у [Field](/components/field).

Длинный список вариантов уберите в [Select](/components/select).

## Установка

```ts install
import { NuiRadio, NuiRadioGroup } from '@numior/kit';
```

## Использование

Разверните варианты в строку, поменяйте размер и состояния группы.

<Configurator name="NuiRadioGroup" />

## Примеры

### Хранить в модели объект

Передайте объект в `value`.

<Example name="radio-group/Objects" />

Радиокнопка и модель сравниваются по ключу значения, по умолчанию это JSON объекта. Если объект
приходит с сервера заново и поля в нём меняются, передайте в `getKey` функцию, которая вернёт его
код.

## Доступность

Радиокнопки нативные: стрелки переключают выбор, а форма отправляет значение под общим `name`.
Экранный диктор читает подпись, подсказку и ошибку группы, когда фокус входит в неё.
