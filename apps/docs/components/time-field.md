# Time field

`NuiTimeField` редактирует время как набор сегментов: часы, минуты, при необходимости секунды
и AM/PM. Порядок сегментов, разделители и цикл выводятся из локали, а модель остаётся строкой
`HH:mm` без часового пояса. Кнопка с часами открывает барабаны.

<Example name="time-field/Basic" />

## Установка

```ts
import { NuiTimeField } from '@numior/vue';
import '@numior/vue/styles/field.css';
import '@numior/vue/styles/time-field.css';
```

## Примеры

### Локали

Одно значение, три локали: 24-часовой цикл, 12-часовой с периодом и арабские цифры. `hourCycle`
задаёт цикл принудительно.

<Example name="time-field/Locales" />

### Секунды

`seconds` добавляет сегмент секунд, модель становится `HH:mm:ss`; `step` в минуту даёт
барабанам все значения.

<Example name="time-field/Seconds" />

## Поведение

Цифры вводятся посегментно: сегмент заполняется и переходит к следующему, как только следующая
цифра не может продолжить число. Модель становится `null`, пока хотя бы один сегмент пуст, а
полное значение вне `min` и `max` зажимается при уходе фокуса. Барабаны показывают минуты с
шагом `step` и подсвечивают недоступные значения.

## Доступность

Сегменты — нативные `<input role="spinbutton">` с `aria-valuenow` и `aria-valuetext`, подписи
берутся из `Intl.DisplayNames`. В порядке табуляции остаётся один сегмент, ряд сегментов идёт
слева направо даже в RTL. Барабаны — `role="group"`, каждая колонка — `role="spinbutton"`.
