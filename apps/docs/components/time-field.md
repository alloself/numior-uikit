# Time field

Поле для времени.

<Example name="time-field/Basic" />

Время хранится строкой `09:30` без часового пояса. Формат часов и порядок частей поле берёт из
языка приложения.

## Установка

```ts install
import { NuiTimeField } from '@numior/vue';
```

## Использование

Добавьте секунды, поменяйте формат часов и шаг списка времени.

## Поведение

Когда часть заполнена, курсор сам переходит к следующей, а пока хотя бы одна часть пуста, в модели
`null`. Время раньше `min` или позже `max` при уходе из поля сменяется ближайшей границей.

## Доступность

Экранный диктор называет каждую часть: «час», «минута». Tab попадает только в одну часть, а между
частями ходят стрелки влево и вправо. Части идут слева направо и на страницах с текстом справа
налево.
