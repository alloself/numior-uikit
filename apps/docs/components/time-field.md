# Time field

`NuiTimeField` — поле для ввода времени: часы и минуты, при необходимости секунды. Время можно
набрать с клавиатуры или выбрать на барабанах, которые открывает кнопка с часами.

<Example name="time-field/Basic" />

Значение модели — строка вида `09:30` без часового пояса. Порядок частей, разделитель и формат
часов (24 или 12 с AM/PM) поле берёт из локали приложения, а свойство `locale` задаёт другую.

## Установка

```ts
import { NuiTimeField } from '@numior/vue';
import '@numior/vue/styles/field.css';
import '@numior/vue/styles/time-field.css';
```

## Примеры

### Время в разных языках

Здесь одно и то же значение показано в трёх локалях: `ru-RU` с 24-часовым форматом, `en-US` с
AM/PM и `ar-EG` с арабскими цифрами. Свойство `hourCycle` задаёт формат часов независимо от
языка.

<Example name="time-field/Locales" />

### Секунды

Свойство `seconds` добавляет секунды, и значение принимает вид `09:30:15`. Барабан минут по
умолчанию идёт с шагом 15 минут, а `:step="1"` показывает на нём каждую минуту.

## Поведение

Цифры набираются по частям: когда в часах или минутах уже не может быть следующей цифры, курсор
переходит дальше сам. Пока хотя бы одна часть пуста, значение модели — `null`.

Время раньше `min` или позже `max` при уходе из поля заменяется ближайшей границей. На барабанах
такое время приглушено.

## Доступность

Каждая часть времени — `<input role="spinbutton">` с `aria-valuenow` и `aria-valuetext`, а
названия частей («час», «минута») приходят из `Intl.DisplayNames`. Tab попадает только в одну
часть, а между частями ходят стрелки влево и вправо.

Части времени идут слева направо даже при письме справа налево. Барабаны — `role="group"`, а
каждая колонка барабана — `role="spinbutton"`.
