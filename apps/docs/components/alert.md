# Alert

Сообщение в потоке страницы.

<Example name="alert/Basic" />

Уведомление поверх страницы, которое пропадает само, показывает [Toast](/components/toast).

## Установка

```ts install
import { NuiAlert } from '@numior/kit';
```

## Использование

Поменяйте тон, вид и заголовок сообщения.

<Configurator name="NuiAlert" />

## Примеры

### Дать закрыть сообщение и предложить действие

Добавьте `closable` и положите кнопки в слот `actions`.

<Example name="alert/Closable" />

Внутри сообщения `soft` берите кнопки `solid` или `outline`: кнопка `soft` того же тона сливается с
фоном.

## Доступность

Сообщение с `tone="error"` получает `role="alert"`, и экранный диктор зачитывает его сразу после
появления. Остальные сообщения читаются как обычный текст страницы, иконка в них декоративная.
