# Tabs

Вкладки для разделов одного экрана.

<Example name="tabs/Basic" />

Открытая вкладка хранится в `v-model`.

## Установка

```ts install
import { NuiTab, NuiTabList, NuiTabPanel, NuiTabs } from '@numior/kit';
```

## Использование

Поменяйте вид, размер и направление вкладок на списке заказов.

<Configurator name="NuiTabs" />

## Примеры

### Собрать вкладки из данных

Передайте массив `tabs` и слот `panel`.

<Example name="tabs/Data" />

Без слота вкладки работают как переключатель: выбранная вкладка приходит в `v-model`, а что
показать, решает приложение.

### Закрывать вкладки

Добавьте `closable` и уберите вкладку в обработчике `close`.

<Example name="tabs/Closable" />

Вкладку закрывают крестиком, кликом средней кнопкой мыши и клавишей Delete. У вкладок из `tabs`
поле `closable` задаётся в описании вкладки, а событие `close` с её значением приходит на
`NuiTabs`.

### Связать вкладки с маршрутами

Передайте `links`.

<Example name="tabs/Links" />

Ссылки рисует `RouterLink`, `NuxtLink` или компонент из `createNuiConfig({ link })`, а без
роутера — обычный `<a>`. В `v-model` лежит ключ текущей страницы: строковый `to` или ключ,
который вернул `getKey` для адреса-объекта.

## Поведение

Стрелки ходят по кругу и пропускают отключённые вкладки. Если не задать начальное значение
`v-model`, ни одна вкладка не открыта.

Когда вкладки не помещаются в ширину, список прокручивается жестом, колесом мыши и кнопками
со стрелками. Кнопки появляются у того края, за которым есть скрытые вкладки. Пока список можно
прокрутить в сторону колеса, страница не прокручивается.

Выбранная вкладка и вкладка с фокусом всегда оказываются на виду. Вертикальный список не
прокручивается.

Скрытые панели остаются в DOM. С `lazy` панель рендерится только тогда, когда её впервые
открывают.

Подчёркивание и подложка переезжают за открытой вкладкой, даже если меняется подпись или вкладки
добавляются и удаляются. Когда закрывают вкладку с фокусом, фокус переходит на открытую.
Отключённая вкладка не закрывается.

## Доступность

Стрелки сразу открывают соседнюю вкладку, а с `activation="manual"` только переводят на неё
фокус, и вкладка открывается по Enter или Space.

В порядке табуляции из всего списка стоит только открытая вкладка. Крестик скрыт от экранных
дикторов, потому что в списке вкладок допустимы только сами вкладки. С клавиатуры вкладку
закрывает Delete, как советует паттерн WAI-ARIA.

Панель получает фокус по Tab, чтобы до её текста можно было дойти с клавиатуры. Если в панели
всегда есть кнопки или ссылки, эта остановка не нужна: уберите её через `:focusable="false"`.

Если вкладки собраны из `tabs` без слота `panel`, панелей нет, и `aria-controls` у вкладок тоже
нет.

Вкладки-ссылки размечены как навигация: `nav` с подписью из `label` и ссылки без роли `tab`.
Текущая страница получает `aria-current="page"`. Каждая ссылка стоит в порядке табуляции, а
стрелки по ним не ходят.
