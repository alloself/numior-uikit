# Tabs

`NuiTabs` — вкладки по паттерну WAI-ARIA из частей `NuiTabList`, `NuiTab` и `NuiTabPanel`.
Стрелки переключают вкладки сразу, `activation="manual"` только двигает фокус; вариант `line`
подчёркивает активную вкладку, `soft` двигает подложку.

<Example name="tabs/Basic" />

## Установка

```ts
import { NuiTab, NuiTabList, NuiTabPanel, NuiTabs } from '@numior/vue';
import '@numior/vue/styles/tabs.css';
```

## Примеры

### Вкладки из данных

`tabs` собирает список из данных, слот `panel` рендерит панель каждой вкладки.

<Example name="tabs/Data" />

### Вертикальный список

`orientation="vertical"` ставит список в колонку; стрелки вверх и вниз ходят по вкладкам.

<Example name="tabs/Vertical" />

### Закрываемые вкладки

`closable` рисует на вкладке крестик. Событие `close` приходит по крестику, по средней кнопке
мыши и по Delete; убирает вкладку приложение. Вкладка из `tabs` берёт `closable` из своего
описания, а `close` со значением вкладки приходит на `NuiTabs`.

## Поведение

Активная вкладка — единственная точка табуляции в списке; стрелки ходят по кругу и пропускают
отключённые вкладки. Панели остаются в DOM и скрываются, `lazy` откладывает рендер до первого
показа. Без начального `v-model` ни одна вкладка не выбрана.

Индикатор следует за вкладками: подпись может меняться, вкладки — приходить и уходить. Фокус
закрытой вкладки переходит на выбранную. Отключённая вкладка не закрывается.

## Доступность

Крестик скрыт от экранных дикторов: в списке вкладок допустимы только сами вкладки. С клавиатуры
вкладку закрывает Delete, как советует паттерн WAI-ARIA.

Панель — остановка Tab, чтобы до её текста можно было дойти с клавиатуры. Если в панели всегда есть
свои кнопки и ссылки, паттерн WAI-ARIA эту остановку не требует, и `:focusable="false"` её убирает.
Щелчок по пустому месту такой панели больше не обводит её рамкой фокуса.
