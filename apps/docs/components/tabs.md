# Tabs

`NuiTabs` — вкладки для переключения между разделами одного экрана. Список вкладок собирается из
`NuiTabList` и `NuiTab`, а содержимое каждой вкладки кладётся в `NuiTabPanel`.

<Example name="tabs/Basic" />

Открытая вкладка хранится в `v-model`. Стрелки сразу открывают соседнюю вкладку, а с
`activation="manual"` только переводят на неё фокус, и вкладка открывается по Enter или Space.

## Установка

```ts
import { NuiTab, NuiTabList, NuiTabPanel, NuiTabs } from '@numior/vue';
import '@numior/vue/styles/tabs.css';
```

## Примеры

### Вкладки из данных

Передайте массив `tabs`, чтобы собрать вкладки из данных, а содержимое задайте слотом `panel`.
Без слота `NuiTabs` работает как переключатель: выбранная вкладка приходит в `v-model`, а что
показать, решает приложение.

Вариант `soft` выделяет открытую вкладку подложкой, вариант по умолчанию `line` — подчёркиванием.

<Example name="tabs/Data" />

### Вертикальные вкладки

С `orientation="vertical"` вкладки встают в колонку, а переключаются стрелками вверх и вниз.

<Example name="tabs/Vertical" />

### Закрываемые вкладки

Свойство `closable` добавляет на вкладку крестик. Событие `close` приходит по крестику, по
щелчку средней кнопкой мыши и по Delete, а убирает вкладку из списка приложение.

У вкладок из `tabs` свойство `closable` задаётся в описании вкладки. Событие `close` со значением
вкладки тогда приходит на `NuiTabs`.

<Example name="tabs/Closable" />

### Вкладки-ссылки

Для переходов между страницами передайте `links` вместо `tabs`. Каждый пункт — ссылка с адресом
`to`, а вид остаётся тем же. Ссылки строятся через общий помощник кита: `RouterLink`, `NuxtLink`
или компонент из `createNuiConfig({ link })`, без роутера — обычный `<a>`.

В `v-model` лежит ключ текущей страницы. Строковый `to` сам служит ключом, а для адреса-объекта
ключ задаёт `getKey`, как у селекта. Щелчок по ссылке без клавиш-модификаторов обновляет модель.

## Поведение

Стрелки ходят по кругу и пропускают отключённые вкладки. Если не задать начальное значение
`v-model`, ни одна вкладка не открыта.

Скрытые панели остаются в DOM. С `lazy` панель рендерится только тогда, когда её впервые
открывают.

Подчёркивание и подложка переезжают за открытой вкладкой, даже если меняется подпись или вкладки
добавляются и удаляются. Когда закрывают вкладку с фокусом, фокус переходит на открытую.
Отключённая вкладка не закрывается.

## Доступность

В порядке табуляции из всего списка стоит только открытая вкладка. Крестик скрыт от экранных
дикторов, потому что в списке вкладок допустимы только сами вкладки. С клавиатуры вкладку
закрывает Delete, как советует паттерн WAI-ARIA.

Панель получает фокус по Tab, чтобы до её текста можно было дойти с клавиатуры. Если в панели
всегда есть кнопки или ссылки, эта остановка не нужна: уберите её через `:focusable="false"`.

Если вкладки собраны из `tabs` без слота `panel`, панелей нет, и `aria-controls` у вкладок тоже
нет.

Вкладки-ссылки размечены как навигация: `nav` с подписью из `label` и ссылки без роли `tab`.
Текущая страница получает `aria-current="page"`. Каждая ссылка стоит в порядке табуляции, а
стрелки по ним не ходят.
