# Date picker

Поле для даты с календарём.

<Example name="date-picker/Basic" />

Дата хранится строкой `YYYY-MM-DD`.

## Установка

```ts
import { NuiDatePicker } from '@numior/kit';
```

## Использование

Откройте календарь и поменяйте размер поля, способ открытия и тексты под ним.

<Configurator name="NuiDatePicker" />

## Примеры

### Выбрать дату и время

Добавьте `time`.

<Example name="date-picker/Time" />

Выбор дня не закрывает календарь, чтобы можно было указать время.

### Открывать календарь кликом

Добавьте `openOnClick`.

<Example name="date-picker/OpenOnClick" />

Фокус остаётся в поле: дату можно набрать, а стрелка вниз переводит фокус в календарь.

## Поведение

- Пустое поле показывает шаблон даты для языка страницы, например `ДД.ММ.ГГГГ`, а разделители
  ставит само.
- Цифра, с которой не начинается ни день, ни месяц, дополняется нулём: 4 превращается в 04.
- Дату можно ввести и в виде `2026-10-05` при любом языке.
- Набранная целиком дата сразу попадает в модель. Если текст при уходе из поля не складывается в
  дату, в поле возвращается прежнее значение.
- Дата раньше `min`, позже `max` или отключённая в `isDateDisabled` не принимается ни с
  клавиатуры, ни в календаре.
