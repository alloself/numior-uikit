# Date picker

`NuiDatePicker` — поле для даты: её можно набрать с клавиатуры или выбрать в
[Calendar](/components/calendar), который открывает кнопка в поле. В модели дата хранится строкой
`YYYY-MM-DD`.

<Example name="date-picker/Basic" />

## Установка

```ts
import { NuiDatePicker } from '@numior/vue';
import '@numior/vue/styles/field.css';
import '@numior/vue/styles/calendar.css';
import '@numior/vue/styles/date-picker.css';
```

## Примеры

### Дата и время

Свойство `time` добавляет под календарём [Time field](/components/time-field), и модель
получает строку вида `2026-09-29T10:30`. Выбор дня в этом режиме не закрывает календарь, чтобы
можно было указать время. `timeStep` задаёт шаг минут, по умолчанию 15.

<Example name="date-picker/Time" />

### Открытие по щелчку

С `openOnClick` календарь открывается щелчком по полю, как выпадающий список. Курсор остаётся в
поле, и дату по-прежнему можно набрать, а стрелка вниз переводит фокус в календарь.

<Example name="date-picker/OpenOnClick" />

## Поведение

Пустое поле показывает шаблон даты для языка страницы, например `ДД.ММ.ГГГГ`. Разделители поле
ставит само, буквы не вводятся. Цифра, с которой не начинается ни день, ни месяц, дополняется
нулём: 4 превращается в 04.

Набранная целиком дата сразу попадает в модель, недописанная модель не меняет. Если при уходе из
поля текст не складывается в дату, в поле возвращается прежнее значение. Дату можно ввести и в
виде `2026-10-05` при любом языке.

Дата раньше `min`, позже `max` или запрещённая функцией `isDateDisabled` не принимается ни с
клавиатуры, ни в календаре. Выбор дня закрывает календарь и возвращает фокус в поле. Передайте
`name`, чтобы форма отправила дату в формате `YYYY-MM-DD`.
