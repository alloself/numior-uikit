# Chip

`NuiChip` — метка для значения, которое выбрал пользователь: тег, фильтр, получатель письма.
Чип можно сделать удаляемым. Для статуса или счётчика возьмите [Badge](/components/badge).

<Example name="chip/Basic" />

## Установка

```ts
import { NuiChip } from '@numior/vue';
import '@numior/vue/styles/chip.css';
```

## Использование

Свойство `tone` задаёт цвет, `variant` — заливку: `soft`, `outline` или `solid`. `icon` ставит
иконку перед текстом.

## Примеры

### Удаляемые фильтры

Передайте `removable`, чтобы в чипе появилась кнопка с крестиком. Нажатие на неё вызывает
событие `remove`, а убрать чип из списка должно ваше приложение.

<Example name="chip/Removable" />

### Размеры и недоступность

Размер `sm` подходит для таблиц и списков, по умолчанию стоит `md`. С `disabled` чип становится
бледнее, а кнопка удаления не нажимается.

<Example name="chip/Sizes" />

## Доступность

Кнопка удаления подписана «Убрать». Если чипов несколько, передайте в `removeLabel` подпись с
названием, например «Убрать фильтр Vue», чтобы экранный диктор различал кнопки.

Кнопка удаления доступна с клавиши Tab. С `:remove-tabbable="false"` Tab её пропускает: так
сделано в [Combobox](/components/combobox), где чипы удаляются с клавиатуры прямо из поля.
