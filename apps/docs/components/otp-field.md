# OTP field

Поле для одноразового кода из SMS, письма или приложения.

<Example name="otp-field/Basic" />

Задайте число символов в `length` и размер групп в `groupSize`. Подпись, подсказка и ошибка
работают как у [Field](/components/field).

## Установка

```ts
import { NuiOtpField } from '@numior/vue';
import '@numior/vue/styles/field.css';
import '@numior/vue/styles/otp-field.css';
```

## Примеры

### Подтвердить вход по SMS

Отправьте код на проверку в обработчике `complete`.

<Example name="otp-field/Sms" />

На время запроса сделайте поле `readonly`, а неверный код сотрите: фокус останется в поле.

Телефон подсказывает код из SMS над клавиатурой, а с `web-otp` Chrome на Android подставляет его
сам. Для этого последняя строка сообщения должна выглядеть как `@example.com #123456`, где
`example.com` — домен вашего сайта.

### Принять резервный код

Разрешите буквы через `charset`.

<Example name="otp-field/Access" />

Строчные буквы поле делает заглавными.

### Скрыть PIN-код

Добавьте `secret`.

<Example name="otp-field/Pin" />

Набранный символ виден одну секунду. Браузер считает такое поле паролем и код из SMS не
подсказывает.

### Проверить код в форме

Оберните поле в `NuiFormField`.

<Example name="otp-field/Form" />

Правило `required()` срабатывает на пустом коде, а `min(6)` — на неполном.

## Поведение

- Ввод: символ встаёт в текущую ячейку, и курсор переходит к следующей.
- Вставка: вставленный код заменяет прежний, пробелы и дефисы из него убираются.
- Удаление: Backspace стирает символ слева, и остальные сдвигаются на его место.
- Модель: в неё попадают только символы кода, без разделителей групп.

Событие `complete` не приходит, когда значение меняет само приложение.

## Доступность

Экранный диктор видит одно текстовое поле с подписью, подсказкой и ошибкой, а ячейки от него
скрыты. Поле с `secret` он объявляет как пароль. При направлении текста справа налево ячейки идут
слева направо, как цифры кода.
