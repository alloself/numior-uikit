# OTP field

`NuiOtpField` принимает одноразовый код из SMS, письма или приложения-аутентификатора. Под
ячейками лежит одно нативное поле, поэтому работают подсказка кода на клавиатуре телефона,
вставка и менеджеры паролей.

## Установка

```ts
import { NuiOtpField } from '@numior/vue';
import '@numior/vue/styles/field.css';
import '@numior/vue/styles/otp-field.css';
```

## Примеры

### Резервный код

`charset="alphanumeric"` принимает латиницу и цифры и переводит буквы в верхний регистр.
`groupSize` делит ячейки на группы, последняя группа может быть короче.

<Example name="otp-field/Access" />

### PIN-код

`secret` прячет символы за точками: только что введённая цифра видна секунду, потом
сворачивается в точку. Браузер считает такое поле паролем и не подсказывает коды из SMS.

<Example name="otp-field/Pin" />

### Состояния

`placeholder` рисует символ в пустых ячейках. Код в поле только для чтения можно выделить и
скопировать, выключенное поле фокус пропускает.

<Example name="otp-field/States" />

### Проверка в форме

Внутри `NuiFormField` поле проверяется обычными правилами: `required()` ловит пустой код, а
`min(6)` — неполный. Ошибку сервера форма показывает под ячейками.

<Example name="otp-field/Form" />

### Подтверждение по SMS

Событие `complete` приходит, как только код набран целиком, и запускает проверку. Пока идёт
запрос, поле только для чтения; неверный код очищается, а фокус остаётся в поле.

<Example name="otp-field/Sms" />

`web-otp` читает код из SMS через WebOTP в Chrome на Android. Для этого последняя строка
сообщения должна быть вида `@example.com #123456` с доменом сайта.

## Поведение

Символ попадает в активную ячейку, и активной становится следующая. Клик по заполненной
ячейке выделяет её, и новый символ заменяет старый. Клик по пустой ставит курсор после
последнего символа.

Вставка полного кода заменяет весь код, пробелы и дефисы отбрасываются. Короткая вставка
пишется поверх ячеек начиная с активной. Цифры других систем письма приводятся к ASCII.

В модели лежат только введённые символы без разделителей. `complete` не срабатывает, когда
значение меняет само приложение.

## Доступность

Экранный чтец видит одно текстовое поле с подписью, описанием и ошибкой. Ячейки скрыты от
него, плейсхолдер не озвучивается, а в режиме `secret` чтец называет поле паролем. Ряд ячеек
идёт слева направо даже в RTL.
