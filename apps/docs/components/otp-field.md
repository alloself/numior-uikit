# OTP field

`NuiOtpField` — поле для одноразового кода из SMS, письма или приложения-аутентификатора.
Телефон подсказывает код из SMS прямо над клавиатурой, а вставка и менеджеры паролей работают как
в обычном поле.

<Example name="otp-field/Basic" />

По умолчанию код состоит из шести цифр, `length` меняет их число. `groupSize` делит ячейки на
группы: при `3` код читается как «123 456».

## Установка

```ts
import { NuiOtpField } from '@numior/vue';
import '@numior/vue/styles/field.css';
import '@numior/vue/styles/otp-field.css';
```

## Примеры

### Резервный код

`charset="alphanumeric"` разрешает латинские буквы и цифры, буквы при вводе становятся
заглавными. Если длина не делится на `groupSize`, последняя группа выходит короче.

<Example name="otp-field/Access" />

### PIN-код

С `secret` символы скрываются за точками, только что набранный виден одну секунду. Браузер
считает такое поле паролем, поэтому код из SMS не подсказывает.

<Example name="otp-field/Pin" />

### Состояния

`placeholder` выводит символ в пустых ячейках, например `○`. Код в поле `readonly` можно
выделить и скопировать, а поле `disabled` пропускается при переходе по Tab.

<Example name="otp-field/States" />

### Проверка в форме

Внутри `NuiFormField` к коду применяются обычные правила формы: `required()` срабатывает на
пустом коде, `min(6)` — на неполном. Ошибку с сервера форма показывает под ячейками.

<Example name="otp-field/Form" />

### Подтверждение по SMS

Событие `complete` приходит, когда набран последний символ: в обработчике отправьте код на
проверку. В примере поле на время запроса становится `readonly`, а неверный код стирается, и
фокус остаётся в поле.

<Example name="otp-field/Sms" />

С `web-otp` Chrome на Android сам подставляет код из SMS. Для этого последняя строка сообщения
должна выглядеть как `@example.com #123456`, где `example.com` — домен вашего сайта.

## Поведение

Набранный символ встаёт в текущую ячейку, и курсор переходит к следующей. Щелчок по заполненной
ячейке выделяет её, и новый символ заменит старый. Щелчок по пустой ячейке ставит курсор после
последнего символа.

Вставленный целиком код заменяет прежний, пробелы и дефисы из него убираются. Короткий фрагмент
вписывается в ячейки начиная с текущей. Цифры других систем письма, например арабские
восточные, превращаются в обычные.

В модель попадают только набранные символы, без пробелов между группами. Если значение меняет
само приложение, `complete` не приходит.

## Доступность

Экранный диктор видит одно текстовое поле с подписью, описанием и ошибкой, а ячейки от него
скрыты. Символ из `placeholder` диктор не читает, а поле с `secret` объявляет как пароль. При
письме справа налево ячейки всё равно идут слева направо, как цифры кода.
