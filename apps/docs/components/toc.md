# Toc

`NuiToc` — оглавление статьи «На странице»: список ссылок на заголовки, в котором текущий
пункт следует за прокруткой. Правая колонка этой документации собрана на нём.

<Example name="toc/Basic" />

## Установка

```ts
import { NuiToc } from '@numior/vue';
import '@numior/vue/styles/toc.css';
```

## Поведение

Текущим считается последний заголовок, верх которого выше линии `line`: доли высоты окна
или контейнера `root`, по умолчанию 0.2. Клик по ссылке сразу помечает её и держит
пометку, пока прокрутка не остановится, поэтому пункт не перескакивает на соседний. Пункты
берутся из `items`, вложенные `children` дают второй и третий уровни.

## Доступность

Корень — `nav` с именем из `label` или заголовка, ссылки — обычные `<a href="#id">`;
текущая помечена `aria-current="location"`.
