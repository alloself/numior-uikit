# Toc

Оглавление статьи с подсветкой текущего раздела.

<Example name="toc/Basic" />

Передайте заголовки в `items`.

## Установка

```ts install
import { NuiToc } from '@numior/vue';
```

## Поведение

Подсвечен последний заголовок, который при прокрутке поднялся выше линии `line`. Линия задаётся
долей высоты окна, по умолчанию `0.2`, то есть пятая часть сверху. Если статья прокручивается
внутри своего блока, передайте его в `root`.

После клика по ссылке подсветка сразу встаёт на неё и не перескакивает на соседний пункт, пока
прокрутка не закончится. Событие `select` приходит с `id` выбранного заголовка.

## Доступность

Оглавление — элемент `nav`, его имя для экранных дикторов берётся из `label`, а без него — из
заголовка «На странице». Ссылки — обычные `<a href="#id">`, а у текущей стоит
`aria-current="location"`.
