# Badge

`NuiBadge` — небольшая метка со статусом, счётчиком или цветной точкой: «Черновик», «Оплачен»,
«3». Метку, которую пользователь может убрать, показывает [Chip](/components/chip).

<Example name="badge/Basic" />

## Установка

```ts
import { NuiBadge } from '@numior/vue';
import '@numior/vue/styles/badge.css';
```

## Использование

Свойство `tone` задаёт цвет, `variant` — заливку: `soft`, `outline` или `solid`. `size`
принимает `sm` и `md`.

<Configurator name="NuiBadge" />

## Примеры

### Счётчик, точка и угол

Свойство `count` выводит число. Если оно больше `max`, бейдж показывает `max` с плюсом: при
`max` по умолчанию это «99+». `dot` оставляет от бейджа одну точку.

<Example name="badge/Count" />

С `floating` бейдж встаёт в верхний угол родителя, например кнопки: справа, а при письме справа
налево — слева. Родителю нужен `position: relative`.

## Доступность

Текст и число бейджа экранный диктор читает вместе с окружающим текстом. Точку он называет по
`label`, а точку без `label` пропускает.
