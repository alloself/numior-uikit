# Breadcrumbs

`NuiBreadcrumbs` показывает путь от главной страницы до текущей. Каждый шаг пути — ссылка,
последний шаг — название текущей страницы.

<Example name="breadcrumbs/Basic" />

## Установка

```ts
import { NuiBreadcrumbs } from '@numior/vue';
import '@numior/vue/styles/link.css';
import '@numior/vue/styles/breadcrumbs.css';
```

## Использование

Сверните длинный путь до нужного числа шагов и подберите разделитель.

<Configurator name="NuiBreadcrumbs" />

## Примеры

### Длинный путь

Свойство `maxItems` ограничивает число видимых шагов. Первый и последние шаги остаются на месте,
середина сворачивается в кнопку «…», которая открывает меню со скрытыми ссылками.

<Example name="breadcrumbs/Collapsed" />

### Своя крошка

Слот `item` заменяет ссылку шага своей разметкой. Слот получает `item`, `index` и `current`, а
разделители и сворачивание компонент рисует сам.

<Example name="breadcrumbs/Custom" />

## Поведение

Шаги передаются в `items`: у каждого есть `label`, адрес в `href` или `to` и необязательная
`icon`. С `to` шаг становится `RouterLink` или `NuxtLink` приложения, свойство `as` подставляет
другой компонент ссылки. Ссылки в меню «…» работают так же.

Свойство `separator` меняет иконку между шагами, по умолчанию это стрелка. При письме справа
налево стрелка разворачивается.

## Доступность

Цепочка — ориентир `<nav>` с подписью из `label`, по умолчанию «Навигационная цепочка». Текущая
страница отмечена `aria-current="page"` и не ссылается сама на себя. Ссылки не ниже 24px, как
требует WCAG 2.5.8.
