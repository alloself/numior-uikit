# Breadcrumbs

Путь от главной страницы до текущей.

<Example name="breadcrumbs/Basic" />

Опишите шаги в `items`:

- `label` — подпись шага;
- `href` или `to` — адрес, с `to` шаг станет `RouterLink` или `NuxtLink` приложения;
- `icon` — иконка перед подписью.

Последний шаг — текущая страница, адрес ему не нужен.

## Установка

```ts install
import { NuiBreadcrumbs } from '@numior/kit';
```

## Использование

Сверните длинный путь до нужного числа шагов и подберите разделитель.

## Поведение

Иконка из `separator` стоит между шагами и разворачивается при направлении текста справа налево.

## Доступность

Цепочка — ориентир `<nav>` с подписью из `label`, по умолчанию «Навигационная цепочка». Текущая
страница отмечена `aria-current="page"` и не ссылается сама на себя. Ссылки не ниже 24px, как
требует WCAG 2.5.8.
