# Input

`NuiInput` — однострочное текстовое поле для имени, почты, телефона, поиска. Подпись, подсказку
и ошибку оно выводит само из `label`, `description` и `error`.

<Example name="input/Basic" />

## Установка

```ts
import { NuiInput } from '@numior/vue';
import '@numior/vue/styles/field.css';
import '@numior/vue/styles/input.css';
```

## Примеры

### Префикс и суффикс

Слоты `prefix` и `suffix` ставят текст или иконку внутри рамки перед значением и после него,
например `@` перед логином или `.ru` после домена. В значение поля они не попадают.

<Example name="input/Affixes" />

### Маска

Свойство `mask` форматирует текст при вводе: `#` — цифра, `A` — буква, `*` — буква или цифра.
Остальные символы маски, например скобки и дефисы в `+7 (###) ###-##-##`, поле подставляет само.
С `v-model.unmasked` в модель попадают только введённые цифры и буквы.

<Example name="input/Mask" />

### Ленивое обновление

С `v-model.lazy` значение попадает в модель, когда пользователь уходит из поля или нажимает
Enter, а не при каждом символе. `.trim` убирает пробелы в начале и в конце.

Пока текст набирается через редактор метода ввода (иероглифы, подсказки клавиатуры Android),
поле не трогает ни маску, ни модель: значение попадает в них, когда набор слова закончен. Так же
ведёт себя `v-model` на обычном `<input>`.

<Example name="input/Lazy" />

### Состояния

С `readonly` текст нельзя изменить, но можно выделить и скопировать, а `disabled` выключает поле
целиком. `error` подсвечивает рамку и показывает текст ошибки под полем.

<Example name="input/States" />

## Доступность

Атрибуты `placeholder`, `name`, `autocomplete`, `inputmode` и обработчики событий попадают на
сам `<input>`, а `class` и `style` — на рамку вокруг него. Экранный диктор читает подпись,
подсказку и ошибку вместе с полем.
