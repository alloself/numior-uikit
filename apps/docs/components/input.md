# Input

Однострочное текстовое поле.

<Example name="input/Basic" />

Подпись, подсказку и ошибку задайте в `label`, `description` и `error`: они работают как у
[Field](/components/field).

## Установка

```ts install
import { NuiInput } from '@numior/vue';
```

## Использование

Поменяйте тип, размер и состояния поля.

## Примеры

### Добавить иконку или единицу

Положите текст или иконку в слоты `prefix` и `suffix`.

<Example name="input/Affixes" />

В значение поля они не попадают.

### Ввести телефон по маске

Опишите формат в `mask`.

<Example name="input/Mask" />

| Символ маски | Что принимает   |
| ------------ | --------------- |
| `#`          | Цифру           |
| `A`          | Букву           |
| `*`          | Букву или цифру |

Остальные символы маски, например скобки и дефисы, поле подставляет само. С `v-model.unmasked` в
модель попадают только введённые цифры и буквы.

Пока слово набирается через метод ввода (иероглифы, подсказки клавиатуры Android), маска и
модель ждут конца набора, как `v-model` у обычного `<input>`.

### Обновлять модель после ввода

Добавьте модификатор `.lazy`, и модель изменится, когда пользователь уйдёт из поля или нажмёт Enter.

<Example name="input/Lazy" />

Модификатор `.trim` убирает пробелы в начале и в конце текста.

## Доступность

Атрибуты `placeholder`, `name`, `autocomplete`, `inputmode` и обработчики событий попадают на
сам `<input>`, а `class` и `style` — на рамку вокруг него. Экранный диктор читает подпись,
подсказку и ошибку вместе с полем.
