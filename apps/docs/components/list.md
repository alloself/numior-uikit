# List

`NuiList` — вертикальный список строк: файлы, контакты, настройки, пункты меню. Строки задаются
компонентами `NuiListItem` или массивом `items`, а в каждой могут быть иконка, подпись и пояснение.

<Example name="list/Basic" />

Строка с `href` или `to` работает как ссылка, строка с `interactive` — как кнопка. Оформление
выбирает `variant`: `plain`, `divided` с линиями между строками, `outline` в рамке, `floating` для
выпадающей панели и `nav` для меню.

## Установка

```ts
import { NuiList, NuiListItem } from '@numior/vue';
import '@numior/vue/styles/list.css';
```

## Примеры

### Выбор значений

С `selectable="single"` в списке выбирают одно значение, оно хранится в `v-model`. С
`selectable="multiple"` можно отметить несколько, и они хранятся в `v-model:values`. Отключённые
варианты остаются на виду, но выбрать их нельзя.

<Example name="list/Selectable" />

### Навигация

`variant="nav"` выводит компактные строки без линий, из них собрано боковое меню
[Sidebar](/components/sidebar). Свойство `current` отмечает открытый раздел, а `badge` и
`shortcut` показывают у правого края счётчик и сочетание клавиш.

<Example name="list/Nav" />

### Группы

В `items` можно передать группы вида `{ label, items }`: у каждой группы появится заголовок,
например «Европа» и «Азия». Стрелки переходят между вариантами всех групп подряд.

<Example name="list/Groups" />

## Поведение

В обычном списке ссылки и кнопки получают фокус по Tab, как везде на странице. В списке с выбором
Tab попадает только на одну строку, дальше фокус переводят стрелки или первые буквы подписи.

Тот же список в варианте `floating` открывается в выпадающих списках `NuiSelect` и `NuiCombobox`.
