# Layout

Каркас экрана приложения с боковым меню и верхней панелью.

<Example name="layout/Basic" />

Положите [Sidebar](/components/sidebar) в слот `sidebar`, а `NuiAppBar` — в слот `header`.
`v-model:open` хранит, раскрыто ли меню на широком экране, а `v-model:mobileOpen` — открыто ли оно
на телефоне.

## Установка

```ts install
import { NuiAppBar, NuiLayout } from '@numior/vue';
```

## Примеры

### Растянуть панель на всю ширину

Задайте `header="full"`.

<Example name="layout/Full" />

Слот `end` добавляет колонку справа, например для оглавления. С `sticky` меню и колонки не уезжают
при прокрутке, а каждая прокручивается сама.

## Поведение

- Слот `footer` выводит подвал: с `header="full"` он занимает всю ширину под меню и содержимым, с
  `header="inset"` стоит под содержимым.
- На телефоне меню прячется в [Drawer](/components/drawer). Его открывает кнопка
  `NuiSidebarTrigger`, а выбор пункта закрывает.
- Когда меню уходит в Drawer, решает медиазапрос `mobileQuery`. По умолчанию это экран не шире
  48rem.
- Ctrl+B, а на Mac — Cmd+B, сворачивает и раскрывает меню, если фокус не в поле ввода.
- Панель рядом с меню стоит на отступе содержимого `--spacing-layout-gutter`. Над меню с
  `collapsible="icon"` полная панель ставит кнопку по центру колонки иконок, а остальное — на тот
  же отступ. Дайте этот отступ содержимому, например классом `px-layout-gutter`.

До загрузки скриптов экран считается широким, поэтому страница с сервера выглядит так же, как
первый кадр в браузере.

## Доступность

Область содержимого выводится как `<main>`, верхняя панель — как `<header>`. Кнопка меню сообщает
экранному диктору, открыто ли меню.

Первой на странице стоит ссылка «К содержимому». Она видна, только когда до неё доходят клавишей
Tab, и переводит фокус сразу к содержимому мимо меню. Текст меняет `skipLabel`, а
`:skip-link="false"` убирает ссылку, если на странице уже есть своя.
