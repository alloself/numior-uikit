# Layout

`NuiLayout` размечает экран приложения: боковое меню слева, верхнюю панель `NuiAppBar` и область
с содержимым страницы. Меню собирается из [Sidebar](/components/sidebar) и кладётся в слот
`sidebar`.

<Example name="layout/Basic" />

`v-model:open` хранит, раскрыто ли меню на широком экране, а `v-model:mobileOpen` — открыто ли оно
на телефоне.

## Установка

```ts
import { NuiAppBar, NuiLayout } from '@numior/vue';
import '@numior/vue/styles/layout.css';
import '@numior/vue/styles/skip-link.css';
```

## Примеры

### Панель на всю ширину и колонка справа

С `header="full"` верхняя панель растягивается на всю ширину над боковым меню. Слот `end`
добавляет справа колонку, например для оглавления. С `sticky` меню и колонки не уезжают при
прокрутке, а каждая прокручивается сама.

## Поведение

Слот `footer` выводит подвал. С `header="full"` подвал занимает всю ширину под меню и содержимым,
с `header="inset"` стоит под содержимым.

На экране не шире 48rem меню прячется в выезжающую панель [Drawer](/components/drawer). Её
открывает кнопка `NuiSidebarTrigger`, а выбор пункта закрывает. Ширину, с которой это происходит,
задаёт `mobileQuery`.

До загрузки скриптов экран считается широким, поэтому страница с сервера выглядит так же, как
первый кадр в браузере. Ctrl+B, а на Mac — Cmd+B, сворачивает и раскрывает меню, если фокус не в
поле ввода.

## Доступность

Область содержимого выводится как `<main>`, верхняя панель — как `<header>`. Кнопка меню сообщает
экранному диктору, открыто ли меню.

Первой на странице стоит ссылка «К содержимому». Она видна, только когда до неё доходят
клавишей Tab, и переводит фокус сразу к содержимому мимо меню. Текст меняет `skipLabel`, а
`:skip-link="false"` убирает ссылку, если на странице уже есть своя.
