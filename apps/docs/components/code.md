# Code

Блок кода с копированием, номерами строк и подсветкой.

<Example name="code/Basic" />

## Установка

```ts
import { NuiCode } from '@numior/kit';
```

## Использование

Включите номера строк, перенос и сворачивание на выгрузке заказов.

## Подсветка

Блоки с `language` раскрашиваются сами. Shiki загружается при первой подсветке, а грамматика
языка — когда он впервые встретится на странице. Пока подсветка не готова и при серверном
рендеринге код выводится одним цветом, высота блока не меняется.

Одному блоку свой подсветчик задаёт `highlighter`, а `:highlighter="false"` выводит код одним
цветом. Для всего приложения то же задаёт плагин:

```ts
import { createNuiConfig } from '@numior/kit';

app.use(createNuiConfig({ highlighter: false }));
```

Свой подсветчик напишите по сигнатуре `NuiHighlighter`.

<SignatureReference :names="['useHighlighter', 'highlightCode', 'languageOf', 'NuiHighlighter']" />

## Готовые токены

Передайте результат подсветки со сборки в `tokens`, и подсветчик в браузере не понадобится. Каждая
строка в `tokens` — список фрагментов текста с типом: `keyword`, `string`, `comment` и другие.

## Доступность

Кнопка копирования подписана «Скопировать код», а после нажатия экранный диктор сообщает
«Скопировано». Область с кодом получает фокус с клавиатуры, и её можно прокручивать стрелками.
Номера строк не выделяются и не попадают в скопированный текст.
