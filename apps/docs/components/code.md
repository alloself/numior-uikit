# Code

`NuiCode` — блок кода с кнопкой копирования, как в этой документации. Блок умеет выводить
номера строк, выделять отдельные строки и сворачивать длинный листинг.

<Example name="code/Basic" />

## Установка

```ts
import { NuiCode } from '@numior/vue';
import '@numior/vue/styles/button.css';
import '@numior/vue/styles/code.css';
```

## Использование

Код передайте в `code`, язык — в `language`. Свойство `title` выводит над кодом шапку с именем
файла, без него в шапке стоит название языка.

`lineNumbers` нумерует строки, а `highlight` выделяет строки с указанными номерами, например
`[3]`. С `:copyable="false"` кнопки копирования нет.

Включите номера строк, перенос и сворачивание на выгрузке заказов.

## Примеры

### Длинный вывод

Свойство `maxLines` показывает только первые строки кода и добавляет кнопку «Показать всё».
`wrap` переносит длинные строки, чтобы код не прокручивался по горизонтали.

## Подсветчик

Без подсветчика код выводится одним цветом. Чтобы раскрасить синтаксис, подключите готовый
подсветчик на Shiki через плагин:

```ts
import { createNuiConfig } from '@numior/vue';
import { createShikiHighlighter } from '@numior/vue/shiki';

app.use(createNuiConfig({ highlighter: createShikiHighlighter() }));
```

Shiki загружается при первой подсветке, а грамматика каждого языка — когда он впервые встретится
на странице. Пока подсветка не готова и при серверном рендеринге код выводится одним цветом, и
высота блока не меняется.

Свойство `highlighter` задаёт подсветчик для одного блока, `:highlighter="false"` выключает
подсветку. Подсветчик можно написать и свой, его сигнатура — `NuiHighlighter`.

## Поведение

Если код уже раскрашен при сборке, передайте результат в `tokens`, и подсветчик не понадобится.
Каждая строка в `tokens` — список фрагментов текста с типом: `keyword`, `string`, `comment` и
другие.

Цвет каждого типа задаёт переменная темы `--nui-syntax-*`, например `--nui-syntax-keyword`. Без
шапки кнопка копирования стоит в углу блока.

## Доступность

Кнопка копирования подписана «Скопировать код», а после нажатия экранный диктор сообщает
«Скопировано». Область с кодом получает фокус с клавиатуры, и её можно прокручивать стрелками.
Номера строк не выделяются и не попадают в скопированный текст.
