# Textarea

Поле для текста в несколько строк.

<Example name="textarea/Basic" />

Задайте высоту в строках через `rows`. Подпись, подсказка и ошибка работают как у
[Field](/components/field).

## Установка

```ts
import { NuiTextarea } from '@numior/kit';
```

## Использование

Поменяйте число строк и состояния поля.

<Configurator name="NuiTextarea" />

## Примеры

### Разрешить растягивать поле

Выберите направление в `resize`.

<Example name="textarea/Resize" />

По умолчанию поле тянется только по высоте, а `none` запрещает менять размер.

### Обновлять модель после ввода

Добавьте модификатор `.lazy`, и модель изменится, когда пользователь уйдёт из поля.

<Example name="textarea/Lazy" />

Пока текст набирается через редактор метода ввода, модель не меняется: значение попадает в неё,
когда набор слова закончен.

С `.trim` текст попадает в модель без пробелов и пустых строк по краям.

## Доступность

Атрибуты, классы и обработчики событий попадают на сам `<textarea>`. Подпись связана с полем
через `for`, а подсказка и текст ошибки — через `aria-describedby`.
