# Number field

`NuiNumberField` — поле для чисел: цены, количества, скидки в процентах. Число выводится с
разделителями и знаком валюты по правилам локали, а в модель попадает `number` или `null`.

<Example name="number-field/Basic" />

Формат задаёт `formatOptions` — те же настройки, что у `Intl.NumberFormat`: валюта, проценты,
число знаков после запятой. Пока поле в фокусе, текст остаётся таким, каким его набрал
пользователь.

## Установка

```ts
import { NuiNumberField } from '@numior/vue';
import '@numior/vue/styles/field.css';
import '@numior/vue/styles/number-field.css';
```

## Примеры

### Границы и шаг

Свойства `min` и `max` задают допустимый диапазон, а `step` — на сколько меняют число стрелки
и кнопки «плюс» и «минус». Когда поле теряет фокус или нажат Enter, число возвращается в
диапазон и округляется до точности `step`.

`:steppers="false"` убирает кнопки. В поле `readonly` значение не меняют ни кнопки, ни
клавиши.

<Example name="number-field/Bounds" />

### Локаль

Формат числа берётся из языка приложения, свойство `locale` задаёт его для одного поля. При
вводе подходят обычные цифры и цифры локали, её десятичный разделитель и минус в любом
написании.

## Доступность

Поле имеет роль `spinbutton`: экранный диктор называет значение, минимум и максимум в формате
локали. Кнопки «плюс» и «минус» скрыты от диктора и не получают фокус, с клавиатуры их
заменяют стрелки.

На iOS цифровая клавиатура `inputmode="decimal"` не показывает минус. Для отрицательных чисел
передайте `inputmode="text"`.
