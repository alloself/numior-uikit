# Stepper

`NuiStepper` показывает шаги процесса как `<nav>` с упорядоченным списком: пройденные отмечены
галочкой, шаг с ошибкой — крестиком, остальные — номером. Шаги ничего не проверяют сами:
переходом управляет приложение или `NuiSmartForm`.

<Example name="stepper/Basic" />

## Установка

```ts
import { NuiStepper } from '@numior/vue';
import '@numior/vue/styles/stepper.css';
```

## Примеры

### Колонка со статусами

Статус выводится из позиции: шаги до текущего выполнены, после — впереди; явный `status`
побеждает. `:linear="false"` делает кнопками все шаги, кроме `disabled`.

<Example name="stepper/Vertical" />

## Поведение

В линейном режиме кнопками становятся пройденные шаги и текущий, будущие остаются текстом.
Узкий горизонтальный степпер прячет подписи и показывает под индикаторами название текущего
шага и «Шаг 2 из 4». Номера форматируются по локали, в RTL ряд зеркалится.

## Доступность

Ориентир `<nav aria-label>` и список задают структуру; текущий шаг помечен
`aria-current="step"`. Статус читается из скрытого текста в имени шага («Профиль,
выполнено»). Кнопки шагов проходятся по Tab без роуминга фокуса.
