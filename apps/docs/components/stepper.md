# Stepper

Шаги процесса и место пользователя в нём.

<Example name="stepper/Basic" />

Передайте шаги в `steps`; текущий хранится в `v-model`. Данные шага степпер не проверяет: когда
пускать дальше, решает приложение или [Smart form](/components/smart-form).

## Установка

```ts
import { NuiStepper, NuiStepperStep } from '@numior/kit';
```

## Использование

Поставьте шаги столбцом и разрешите переход на любой этап заказа.

<Configurator name="NuiStepper" />

## Примеры

### Показать статусы шагов в колонке

Добавьте шагам `status` и `description`.

<Example name="stepper/Vertical" />

Без `status` шаги до текущего считаются выполненными, а после — предстоящими.

### Показать инструкцию

Передайте шаги детьми `NuiStepperStep` и включите `readonly`.

<Example name="stepper/Guide" />

Под заголовком шага может стоять любое содержимое. Чтобы шаг попал в оглавление страницы, передайте
заголовок `<h3>` в слот `#title`.

## Поведение

Вернуться можно только к пройденным шагам, а с `:linear="false"` — к любому шагу без `disabled`.
В узком контейнере степпер прячет подписи и пишет под кружками название текущего шага и «Шаг 2
из 4».

С `readonly` шаги не выбираются, а без `orientation` встают столбцом.

## Доступность

Степпер — ориентир `<nav>` с нумерованным списком, текущий шаг отмечен `aria-current="step"`.
Экранный диктор читает статус вместе с названием: «Корзина, выполнено».

Кнопки шагов проходятся по Tab одна за другой. С `readonly` степпер — нумерованный список без
ориентира и без кнопок.
