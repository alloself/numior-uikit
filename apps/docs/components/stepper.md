# Stepper

`NuiStepper` показывает, на каком шаге процесса находится пользователь: регистрация, оформление
заказа, настройка проекта. Пройденные шаги отмечены галочкой, шаг с ошибкой — крестиком,
остальные — номером.

<Example name="stepper/Basic" />

Шаги передаются в `steps`, текущий хранится в `v-model` по его `value`. Сам степпер ничего не
проверяет: когда переходить дальше, решает приложение или [Smart form](/components/smart-form).

## Установка

```ts
import { NuiStepper } from '@numior/vue';
import '@numior/vue/styles/stepper.css';
```

## Примеры

### Колонка со статусами

`orientation="vertical"` выстраивает шаги в колонку. Шаги до текущего считаются выполненными, а
после — предстоящими. Свойство `status` у шага задаёт статус вручную, например `error`.

<Example name="stepper/Vertical" />

## Поведение

По умолчанию вернуться можно только к пройденным шагам: они кнопки, а будущие — просто текст. С
`:linear="false"` можно перейти к любому шагу, кроме шагов с `disabled`.

В узком контейнере горизонтальный степпер прячет подписи и пишет под кружками название текущего
шага и «Шаг 2 из 4». Номера выводятся цифрами локали, при письме справа налево шаги идут справа
налево.

## Доступность

Степпер — ориентир `<nav>` с нумерованным списком, текущий шаг отмечен `aria-current="step"`.
Диктор читает статус вместе с названием: «Профиль, выполнено».

Кнопки шагов проходятся по Tab одна за другой.
