# Separator

Линия между блоками страницы или кнопками панели.

<Example name="separator/Basic" />

## Установка

```ts
import { NuiSeparator } from '@numior/kit';
```

## Использование

Поменяйте направление и подпись линии.

<Configurator name="NuiSeparator" />

## Примеры

### Разделить кнопки панели

Задайте `orientation="vertical"`, и линия встанет между кнопками на высоту ряда.

<Example name="separator/Vertical" />

## Доступность

Экранный диктор объявляет разделитель как границу между частями страницы. Если линия только
украшает ряд, передайте `decorative`, и диктор её пропустит.

Подпись из `label` или слота становится именем разделителя: диктор называет её вместе с ролью.
