# Upload

Загрузка файлов перетаскиванием или через диалог выбора.

<Example name="upload/Basic" />

Отправку на сервер описывает ваша функция `upload`:

```ts
type NuiUploadAdapter<R> = (
  file: File,
  context: { onProgress: (fraction: number) => void; signal: AbortSignal },
) => Promise<R>;
```

Вызывайте `onProgress` с долей от 0 до 1, передайте `signal` в запрос, чтобы отмена его прервала,
и верните ответ сервера.

## Установка

```ts install
import { NuiUpload } from '@numior/kit';
```

Отключите `auto` и вызовите загрузку сами.

### Оставить одну кнопку

Задайте `variant="button"`.

### Загрузить аватар

Возьмите `NuiAvatarUpload`.

<Example name="upload/Avatar" />

Чтобы заменить фото, кликните по аватару или перетащите на него файл, а удаляет фото отдельная
кнопка. Файл, который не прошёл проверку, текущее фото не заменяет.

## Поведение

- Проверки: тип по `accept`, размер по `maxSize`, число файлов по `maxFiles` и ваша функция
  `validate`. Отклонённый файл остаётся в списке с причиной, а с `rejected="drop"` в модель не
  попадает.
- Очередь: одновременно загружаются не больше `concurrency` файлов, по умолчанию 3.
- Отмена и повтор: отмена прерывает запрос через `signal`, а после ошибки в строке появляется
  кнопка «Повторить».
- Удаление: убранный из списка файл приходит в событии `remove`, а с сервера его удаляет
  приложение. С `:multiple="false"` новый файл заменяет прежний, а отклонённый прежний не трогает.
  Свойство `disabled` запрещает и добавлять, и удалять файлы.

## Доступность

Клик в любом месте зоны открывает диалог выбора файлов. С клавиатуры файлы выбирает кнопка
«Выбрать файлы», и к ней привязаны подпись, подсказка и ошибка поля.

Строки объявляют прогресс и статус загрузки. У кнопок отмены, повтора и удаления есть имена для
экранных дикторов.
