# Upload

`NuiUpload` принимает файлы перетаскиванием или через диалог, проверяет их и отдаёт каждый
адаптеру `upload`. Сам компонент не делает запросов: модель хранит элементы со статусами.

<Example name="upload/Basic" />

## Установка

```ts
import { NuiUpload } from '@numior/vue';
import '@numior/vue/styles/field.css';
import '@numior/vue/styles/upload.css';
```

## Примеры

### Сетка миниатюр

`layout="grid"` показывает изображения миниатюрами из object URL; для уже загруженных файлов
берётся их `url`.

<Example name="upload/Grid" />

### Загрузка по кнопке

`auto="false"` держит файлы в статусе `queued` до вызова `start()` через ссылку на компонент.

<Example name="upload/Manual" />

### Только кнопка

`variant="button"` убирает зону сброса: остаётся кнопка выбора и список файлов, перетаскивание
не принимается.

<Example name="upload/Button" />

### Аватар

`NuiAvatarUpload` хранит одно изображение: превью в `NuiAvatar`, замена по клику или сбросу
файла на аватар, удаление кнопкой. Отклонённый файл не трогает текущее изображение.

## Поведение

Файлы проходят проверку `accept`, `maxSize`, `maxFiles` и свой `validate`; отклонённые при
`rejected="list"` видны в списке с причиной, при `rejected="drop"` не попадают в модель.
Прошедшие уходят в адаптер не больше `concurrency` одновременно. Отмена абортит запрос через
`signal`, ошибка адаптера оставляет строку с кнопкой повтора, удаление готового файла шлёт
`remove` — удалить его на сервере должно приложение.

В одиночном режиме отклонённая замена не трогает уже выбранный файл. `disabled` закрывает и
приём файлов, и удаление строк.

## Доступность

Вся зона кликабельна, с клавиатуры файлы выбирает кнопка «Выбрать файлы»: на ней подпись,
описание и ошибка поля. Строки объявляют прогресс и статус, кнопки отмены, повтора и
удаления имеют доступные имена.
