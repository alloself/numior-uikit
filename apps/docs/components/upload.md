# Upload

`NuiUpload` — поле для загрузки файлов. Файлы можно перетащить в зону на странице или выбрать в
диалоге, а под зоной видны их список, прогресс загрузки и ошибки.

<Example name="upload/Basic" />

Сами запросы на сервер компонент не отправляет: каждый файл получает функция `upload`. Она
загружает файл, сообщает прогресс через `onProgress` и возвращает результат, например адрес
файла. В `v-model` лежит массив файлов со статусами `queued`, `uploading`, `done` и `error`.

## Установка

```ts
import { NuiUpload } from '@numior/vue';
import '@numior/vue/styles/field.css';
import '@numior/vue/styles/upload.css';
```

## Примеры

### Сетка миниатюр

С `layout="grid"` изображения показываются миниатюрами сразу после выбора, ещё до загрузки. Для
файлов, которые уже загружены, миниатюра берётся из их `url`.

<Example name="upload/Grid" />

### Загрузка по кнопке

С `:auto="false"` выбранные файлы ждут в статусе `queued`. Загрузка начинается, когда приложение
вызовет метод `start()` у ссылки на компонент.

<Example name="upload/Manual" />

### Только кнопка

С `variant="button"` вместо зоны для перетаскивания остаётся одна кнопка выбора и список файлов.
Перетащить файл в такое поле нельзя.

<Example name="upload/Button" />

### Аватар

`NuiAvatarUpload` загружает одно изображение и показывает его в [Avatar](/components/avatar).
Чтобы заменить фото, щёлкните по аватару или перетащите на него новый файл, а удаляет фото
отдельная кнопка.

Если новый файл не прошёл проверку, текущее изображение остаётся на месте.

## Поведение

Каждый файл проходит проверки: тип по `accept`, размер по `maxSize`, число файлов по `maxFiles`
и функцию `validate`. С `rejected="list"`, как по умолчанию, отклонённые файлы остаются в списке
с причиной, а с `rejected="drop"` в модель не попадают.

Одновременно загружаются не больше `concurrency` файлов, по умолчанию 3. Отмена прерывает
запрос через `signal`, а при ошибке в строке появляется кнопка «Повторить».

Удаление загруженного файла присылает событие `remove`, а удалить файл на сервере должно
приложение. С `:multiple="false"` новый файл заменяет прежний, но отклонённый файл прежний не
трогает. Свойство `disabled` запрещает и добавлять файлы, и удалять их.

## Доступность

Щелчок в любом месте зоны открывает диалог выбора файлов. С клавиатуры файлы выбирает кнопка
«Выбрать файлы», и к ней привязаны подпись, подсказка и ошибка поля.

Строки объявляют прогресс и статус загрузки. У кнопок отмены, повтора и удаления есть имена для
экранных дикторов.
