# Accordion

Секции, из которых открыта одна или несколько.

<Example name="accordion/Basic" />

## Установка

```ts
import { NuiAccordion, NuiAccordionItem } from '@numior/kit';
```

## Использование

Поменяйте оформление и посмотрите, как секции открываются по одной и по нескольку.

<Configurator name="NuiAccordion" />

## Примеры

### Открыть несколько секций

Добавьте `multiple`, и открытые секции будут храниться в `v-model:values`.

<Example name="accordion/Multiple" />

## Поведение

Без `multiple` в `v-model` лежит `value` открытой секции или `null`, если все свёрнуты. С
`:collapsible="false"` открытую секцию нельзя свернуть повторным кликом: она закрывается, только
когда открывают другую.

## Доступность

Заголовки секций — кнопки, и экранный диктор сообщает, раскрыта ли секция. Стрелки вверх и вниз
переходят между заголовками по кругу, Home и End — к первому и последнему. Клавиши работают,
только когда фокус на заголовке: в полях внутри секции они двигают курсор как обычно.
