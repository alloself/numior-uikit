# Tree

Вложенные данные, которые раскрываются по уровням.

<Example name="tree/Basic" />

Передайте узлы в `items`, вложенные — в `children`. Выбранный узел приходит в `v-model`, а
раскрытые — в `v-model:expanded`.

## Установка

```ts install
import { NuiTree } from '@numior/vue';
```

## Использование

Поменяйте оформление, размер строк и выбор на дереве категорий магазина.

## Примеры

### Отметить строки метками

Передайте узлу `badge` и `current`.

<Example name="tree/Marks" />

Поле `current` выделяет раздел, открытый сейчас, независимо от выбора.

### Выбор с вложенными узлами

Добавьте `checkable`.

<Example name="tree/Checkable" />

Выбор родителя выбирает всех его потомков, а родитель, у которого выбрана часть детей, отмечен
частично. Значения приходят в `v-model:values` в порядке дерева.

### Ленивая загрузка

Отметьте узел `lazy` и загрузите его детей в обработчике `load`.

<Example name="tree/Lazy" />

Значение узла сразу попадает в `v-model:expanded`, а строка показывает индикатор загрузки, пока
дети не придут в `items`. В дереве с `checkable` дети выбранного узла приходят выбранными.

### Ошибка загрузки

Уберите узел из `v-model:expanded`, когда дети не загрузились.

<Example name="tree/LoadError" />

Индикатор пропадёт, а следующее раскрытие снова пришлёт `load`. Сообщение об ошибке покажите сами,
например в [Alert](/components/alert).

### Большие деревья

Добавьте `virtual` и `height`.

<Example name="tree/Virtual" />

В DOM остаются только строки, которые видны в области прокрутки. При рендере на сервере в HTML
попадают первые 20 строк.

### Загрузка и пустое дерево

Добавьте `loading`, а пустое дерево покажет `emptyLabel`.

## Поведение

Клик по стрелке раскрывает узел, клик по строке выбирает его, двойной клик раскрывает или
сворачивает. В дереве с `checkable` клик по строке, Enter и Space выбирают узел или снимают выбор.

Узел с `children: []` считается конечным и не раскрывается. Строки не бывают ссылками: чтобы
открыть страницу, слушайте событие `select`.

## Доступность

Дерево целиком — одна остановка Tab, а по узлам ходят стрелки. Фокус не теряется, когда строки
уходят из DOM при прокрутке. Экранный диктор называет уровень, позицию и состояние узла.

Если узел в фокусе скрыли снаружи — свернули его родителя через `v-model:expanded` — фокус
переходит на ближайшего видимого предка. Если узел исчез из `items`, фокус получает узел, который
занял его место. Стрелки продолжают движение оттуда, а не с начала дерева.

Пока дети ленивого узла не пришли, диктор называет его свёрнутым. Во время `loading` диктор
узнаёт, что дерево загружается. Пустое дерево — обычный блок без фокуса.
