# Button

`NuiButton` — кнопка для действий: сохранить форму, открыть диалог, удалить запись. Ссылку
внутри текста оформляйте через [Link](/components/link).

<Example name="button/Basic" />

## Установка

```ts
import { NuiButton } from '@numior/vue';
import '@numior/vue/styles/button.css';
```

## Использование

Свойство `variant` задаёт вид кнопки: `solid` (по умолчанию), `soft`, `outline`, `ghost`,
`plain` или `link`. Свойство `tone` задаёт цвет: `primary`, `success`, `error`, `neutral` и
другие.

## Примеры

### Размеры

Свойство `size` принимает `xs`, `sm`, `md` и `lg`, по умолчанию `md`. Размер `inline` считается
от шрифта вокруг и подходит для кнопки внутри строки текста. В компактной плотности все размеры
становятся ниже.

<Example name="button/Sizes" />

### Состояния

`disabled` выключает кнопку. Свойство `loading` показывает индикатор загрузки и блокирует
нажатия, ширина кнопки при этом не меняется, а фокус остаётся на ней.

<Example name="button/States" />

### С иконкой

Свойство `icon` ставит иконку перед текстом, `iconEnd` — после него. Иконку можно положить и в
слот вместе с текстом.

<Example name="button/WithIcon" />

### Только иконка

Кнопка без текста, с одной иконкой, становится квадратной. Подпишите её через `aria-label`,
иначе экранный диктор не сможет её назвать.

<Example name="button/IconOnly" />

Вариант `plain` подходит для кнопок внутри поля: раскрыть список, очистить, показать пароль. У
него нет фона, а приглушённая иконка темнеет при наведении.

### Ссылка

Передайте `href` или `to`, чтобы кнопка стала ссылкой и сохранила оформление. С `to` кнопка
становится `RouterLink` или `NuxtLink` приложения, свойство `as` подставляет другой компонент.

<Example name="button/Link" />

## Доступность

Кнопка остаётся нативным `<button>`, а ссылка — `<a>`, поэтому клавиатура и экранные дикторы
работают с ними как обычно. Во время загрузки кнопка получает `aria-busy` и не выпадает из
порядка табуляции.
