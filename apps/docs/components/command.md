# Command

Палитра команд с поиском.

<Example name="command/Basic" />

## Установка

```ts
import { NuiCommand, NuiCommandDialog } from '@numior/kit';
```

## Использование

Опишите команды в `items`:

| Поле          | Что задаёт                                                                             |
| ------------- | -------------------------------------------------------------------------------------- |
| `value`       | Уникальный ключ команды                                                                |
| `label`       | Название в списке                                                                      |
| `description` | Строку под названием                                                                   |
| `icon`        | Иконку перед названием                                                                 |
| `shortcut`    | Сочетание клавиш справа от названия, например `mod+1`; нажатие обрабатывает приложение |
| `keywords`    | Слова для поиска, которых нет в названии                                               |

Чтобы разбить команды на группы, передайте записи `{ label, items }`. Выбранная команда придёт в
событии `select`.

Наберите запрос в палитре и поменяйте рамку, подсказку в поле и состояние загрузки.

## Примеры

### Открыть палитру в диалоге

Возьмите `NuiCommandDialog` и задайте сочетание в `hotkey`.

<Example name="command/Dialog" />

Без `hotkey` диалог открывается по Ctrl+K, а на macOS — по ⌘K. Здесь стоит Ctrl+J, потому что
Ctrl+K открывает поиск по документации. Выбор команды закрывает диалог, а
`:close-on-select="false"` оставляет его открытым.

## Поведение

Палитра ищет запрос:

- в названии команды;
- в описании;
- в словах из `keywords`.

Регистр, акценты латиницы и разница между «е» и «ё» не важны: «темная» найдёт команду «Тёмная
тема», а «cafe» — «Café». Диалог открывается с пустым запросом, если приложение не задало свой.

### Искать команды на сервере

Отключите поиск в палитре через `:filter="false"` и слушайте событие `search` с текстом запроса:

```vue
<NuiCommand :items="found" :filter="false" :loading="loading" @search="search" />
```

Найденные команды положите в `items`, а пока они загружаются, включите `loading`.

## Доступность

Фокус остаётся в поле поиска, а стрелки переходят по командам. Диалог закрывается по Escape и
возвращает фокус на элемент, с которого его открыли.
