# Card

`NuiCard` — карточка с заголовком, текстом и действиями: тариф, проект, статья. Карточка
целиком может вести по ссылке или работать как кнопка.

<Example name="card/Basic" />

## Установка

```ts
import { NuiCard, NuiCardContent, NuiCardHeader, NuiCardTitle } from '@numior/vue';
import '@numior/vue/styles/card.css';
```

## Анатомия

| Часть                | Что внутри                                                |
| -------------------- | --------------------------------------------------------- |
| `NuiCard`            | Рамка карточки, внутренние отступы, ссылка или кнопка     |
| `NuiCardHeader`      | Заголовок с описанием, справа — слот `actions` для кнопок |
| `NuiCardTitle`       | Заголовок карточки, по умолчанию `<h3>`                   |
| `NuiCardDescription` | Строка под заголовком приглушённым цветом                 |
| `NuiCardContent`     | Основной текст карточки                                   |
| `NuiCardFooter`      | Кнопки внизу карточки                                     |
| `NuiCardMedia`       | Картинка от края до края карточки с заданным соотношением |

## Примеры

### Картинка

`NuiCardMedia` выводит картинку из `src` по всей ширине карточки. Свойство `aspect` задаёт
соотношение сторон, например `3 / 1`, а лишнее обрезается.

<Example name="card/Media" />

### Карточка-ссылка

Передайте `href` или `to`, чтобы по карточке можно было кликнуть в любом месте и перейти по
ссылке. Кнопки в слоте `actions` и в подвале нажимаются отдельно и ссылку не открывают.

<Example name="card/Link" />

### Интерактивная карточка

С `interactive` карточка работает как кнопка: клик в любом её месте вызывает событие `click`.

<Example name="card/Interactive" />

### Варианты и отступы

Свойство `variant` задаёт вид: `outline` с рамкой, `elevated` с тенью или `soft` с заливкой.
`padding` задаёт отступы внутри карточки: `xs`, `sm`, `md` (по умолчанию) или `lg`.

<Example name="card/Variants" />

Отступ `xs` подходит для плотной сетки из множества карточек.

### Заголовок без частей

Свойства `title` и `description` выводят шапку карточки, если своя разметка шапки не нужна.

<Example name="card/Props" />

## Доступность

Карточке-ссылке и интерактивной карточке нужен заголовок: `NuiCardTitle` или свойство `title`.
Экранный диктор называет ссылку или кнопку по этому заголовку, а не по всему тексту карточки.
Рамка фокуса обводит карточку целиком.
