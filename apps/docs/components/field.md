# Field

`NuiField` выводит подпись, подсказку и ошибку вокруг контрола и связывает их с ним для экранных
дикторов. Поля ввода Numior UI показывают эти тексты сами, поэтому `NuiField` нужен, когда в подписи
есть разметка или в поле несколько контролов.

<Example name="field/Basic" />

Свойство `required` добавляет к подписи звёздочку, `error` переводит контрол в состояние ошибки и
показывает текст под ним.

## Установка

```ts
import { NuiField } from '@numior/vue';
import '@numior/vue/styles/field.css';
```

## Примеры

### Подпись с разметкой

Слоты `label`, `description` и `error` принимают разметку вместо текста: ссылку рядом с подписью,
выделенное слово в подсказке.

<Example name="field/Slots" />

### Группа контролов

С `group` поле объединяет несколько контролов под одной подписью, например имя и фамилию.
Экранный диктор называет группу её подписью, а `disabled` выключает все контролы сразу.

<Example name="field/Group" />

### Место под ошибку

`reserveError` заранее оставляет под контролом строку для ошибки. Когда после отправки выводится
сообщение, соседние поля и кнопки не сдвигаются. Свойство `reserveError` у `NuiForm` включает это
для всех полей формы.

<Example name="field/Reserve" />

## Доступность

Щелчок по подписи ставит фокус в контрол, а экранный диктор вместе с полем читает подсказку и
ошибку. Связи есть уже в разметке с сервера, до загрузки скриптов.

Части `NuiFieldLabel`, `NuiFieldDescription` и `NuiFieldError` выводят подпись, подсказку и ошибку
в вашей разметке. Данные они берут из ближайшего `NuiField` или из поля, созданного функцией
`provideField` из `@numior/primitives`.
