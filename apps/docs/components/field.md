# Field

Подпись, подсказка и ошибка вокруг любого контрола.

<Example name="field/Basic" />

Поля ввода Numior UI показывают эти тексты сами, а `NuiField` нужен для подписи с разметкой,
группы контролов или своего контрола.

## Установка

```ts
import { NuiField } from '@numior/kit';
```

## Использование

Допишите описание и ошибку, отметьте поле обязательным или отключите его.

<Configurator name="NuiField" />

## Примеры

### Добавить ссылку к подписи

Передайте разметку в слоты `label`, `description` и `error`.

<Example name="field/Slots" />

### Объединить несколько контролов

Добавьте `group`, и контролы встанут под одной подписью.

<Example name="field/Group" />

Экранный диктор называет группу её подписью, а `disabled` отключает все контролы сразу.

### Не сдвигать форму ошибкой

Включите `reserveError`, и под контролом останется строка для ошибки.

<Example name="field/Reserve" />

То же свойство у `NuiForm` оставляет строку под ошибку у всех полей формы.

## Свой контрол

Части `NuiFieldLabel`, `NuiFieldDescription` и `NuiFieldError` выводят подпись, подсказку и ошибку
в вашей разметке. Данные они берут из ближайшего `NuiField` или из поля, которое создал
`provideField` из `@numior/kit`.

Свой элемент ввода свяжите с полем через [`useFieldControl`](/composables/field-control).

## Доступность

Клик по подписи ставит фокус в контрол, а экранный диктор вместе с полем читает подсказку и
ошибку. Связи есть уже в разметке с сервера, до загрузки скриптов.
