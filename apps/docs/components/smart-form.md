# Smart form

Форма по описанию полей.

<Example name="smart-form/Customer" />

Берите её для типовых форм, например карточки клиента, настроек или фильтров, и для форм, которые
приходят с сервера в JSON. Поля описывает `formConfig<Values>()`, а проверку и отправку ведёт та же
`useForm`, что и в [обычной форме](/components/form).

## Установка

```ts
import { NuiSmartForm, formConfig, useForm } from '@numior/forms';
import '@numior/forms/styles/form.css';
import '@numior/forms/styles/field-array.css';
import '@numior/forms/styles/smart-form.css';
```

## Примеры

### Разбить форму на шаги

Передайте `steps` вместо `fields`.

<Example name="smart-form/Wizard" />

Кнопка «Далее» проверяет поля текущего шага и не пускает дальше, пока в них есть ошибки. К
пройденным шагам можно вернуться кликом по степперу. Открытый шаг хранится в `v-model:step`.

Кнопка последнего шага отправляет форму. Если при отправке ошибка нашлась на другом шаге, форма
откроет этот шаг.

### Выстроить фильтры в строку

Добавьте `inline`.

<Example name="smart-form/Inline" />

Поля встают в строку по ширине содержимого и переносятся, когда места не хватает, а с
`inline="grow"` растягиваются на всю ширину.

## Конфигурация

Поле описывает `field(Component, (v) => v.email, options)`: компонент, функция, которая указывает
на значение в форме, и настройки. В настройках задаются `label`, `description`, `required`,
`rules`, `props` компонента, `when` и `area`.

`props` бывает и функцией от значений формы, когда свойства контрола зависят от других полей.
TypeScript выводит тип значения из функции выбора и сверяет его с моделью компонента. Если
компонент хранит значение не в `v-model`, а в именованной модели, укажите её: `model: 'values'`.

`section({ title, layout, fields })` выводит группу полей под общим заголовком.
`array((v) => v.contacts, { newRow, fields })` выводит повторяемую группу, как контакты в примере,
а поля одной строки описывает отдельный `formConfig<Row>()`.

## Условия и раскладка

Поле, секция или группа видны, пока их `when(values, row)` возвращает `true`. В строке
повторяемой группы `when` получает значения этой строки. Скрытое поле не проверяется и не
отправляется, но его значение сохраняется и вернётся, когда поле появится снова.

`layout` записывается как CSS-свойство `grid-template-areas`. Имена областей — пути полей с
дефисом вместо точки (`address-city`) или их `area`, у секции — `name` или `area`. Строка
раскладки, в которой скрыты все поля, пропадает.

Если ширина формы меньше `36rem`, поля встают в одну колонку, поэтому одна форма подходит и для
диалога, и для телефона.

## Из JSON

`parseFormConfig(json, { controls })` собирает конфигурацию из JSON. В `controls` передайте набор
контролов, например `kitControls` из `@numior/vue/controls`.

```json
[
  {
    "kind": "field",
    "type": "text",
    "name": "name",
    "label": "Имя",
    "rules": [{ "rule": "required" }]
  },
  {
    "kind": "field",
    "type": "text",
    "name": "company",
    "label": "Компания",
    "when": { "path": "kind", "equals": "company" }
  }
]
```

Поле в JSON задают строковый `type` из набора контролов, путь `name`, `props` и правила
`required`, `min`, `max`, `email`, `pattern`. Условие `when` записывается как `{ path, equals }`
или `{ path, in }`. Секции и повторяемые группы получают `kind: "section"` и `kind: "array"` и
свои `fields`.

`props` проверяет сам контрол из набора. Если тип неизвестен, `props` не прошли проверку или
запись не разобрать, вместо `fields` вернётся список `issues` с кодом ошибки и путём до неё.

Правило `pattern`, чей `source` — не регулярное выражение, тоже попадает в `issues`. Путь ведёт до
самого правила, например `fields.0.rules.1`.

`formConfig({ controls }).control('select', (v) => v.country, { props })` берёт компонент из
набора по ключу, и TypeScript знает типы его `props`. Значения полей из JSON имеют тип `unknown`,
потому что их форму определяет присланная конфигурация. Подробнее — в
[useControls](/composables/controls).

## Слоты

Слот с именем, равным пути поля, задаёт содержимое компонента, как радиокнопки `kind` в примере
или подпись флажка. В слот приходят `error`, `invalid`, `touched` и `pending`. В повторяемой
группе имя слота — путь без номера строки, например `contacts.phone`, и в слот приходит ещё `row`.

Слот с именем `путь:after`, например `email:after`, выводит своё содержимое под полем и тоже
получает `row`.

Слот `actions` заменяет кнопки формы. В него приходят `submit`, `reset`, `pending` и `dirty`, а
в пошаговой форме ещё `step`, `first`, `last` и `back`.
