# Kbd

`NuiKbd` показывает клавишу или сочетание клавиш в тексте подсказки, меню или кнопки. Сочетание
записывается так же, как для `useHotkey`: `mod+k` на Mac выглядит как ⌘ K, а в Windows и Linux —
как Ctrl K.

<Example name="kbd/Basic" />

`variant="plain"` выводит клавишу простым текстом, без рамки. `variant="soft"` кладёт клавишу на
полупрозрачную подложку цвета текста: она читается на любом фоне, в том числе в подсказке.

## Установка

```ts
import { NuiKbd } from '@numior/vue';
import '@numior/vue/styles/kbd.css';
```

## Примеры

### Платформа

Свойство `platform` со значением `mac` или `other` задаёт, как выглядят модификаторы: ⌘ ⌥ ⇧ или
Ctrl, Alt и Shift. Без него платформа определяется в браузере после загрузки страницы. На сервере
и до этого момента показываются Ctrl, Alt и Shift.

<Example name="kbd/Platform" />

## Поведение

Стрелки, Enter, Backspace, Delete и Tab выводятся значками: ↑, ↵, ⌫, ⌦, ⇥. Буквы выводятся
заглавными, а названия клавиш — с большой буквы, `escape` превращается в Esc.

Передайте в `keys` массив, чтобы показать несколько сочетаний подряд. Текст, которого нет среди
клавиш, например «Средняя кнопка мыши», положите в слот по умолчанию.

## Доступность

Экранный диктор читает значки по их названиям в Юникоде, например «стрелка вверх». Поэтому рядом
с сочетанием словами напишите, что оно делает: «Нажмите ⌘ K для поиска».
