# Kbd

Клавиша или сочетание клавиш в тексте.

<Example name="kbd/Basic" />

Запишите сочетание как для [`useHotkey`](/composables/hotkey): `mod+k` покажет ⌘ K на Mac и Ctrl K в
Windows и Linux.

## Установка

```ts install
import { NuiKbd } from '@numior/kit';
```

## Обозначения клавиш

| В `keys`                                          | На экране  |
| ------------------------------------------------- | ---------- |
| `arrowup`, `arrowdown`, `arrowleft`, `arrowright` | ↑, ↓, ←, → |
| `enter`                                           | ↵          |
| `backspace`                                       | ⌫          |
| `delete`                                          | ⌦          |
| `tab`                                             | ⇥          |
| `escape`                                          | Esc        |
| `k`                                               | K          |
| `home`                                            | Home       |

Текст, которого нет среди клавиш, например «Средняя кнопка мыши», положите в слот по умолчанию.

## Доступность

Экранный диктор читает значки по их названиям в Юникоде, например «стрелка вверх». Поэтому рядом
с сочетанием словами напишите, что оно делает: «Нажмите ⌘ K, чтобы найти заказ».
