# Select

`NuiSelect` — поле с выпадающим списком для выбора одного или нескольких значений: страны,
города, исполнителя. Если пользователю нужно искать по списку или вводить своё значение, берите
[Combobox](/components/combobox).

<Example name="select/Basic" />

Варианты передаются в `options` записями `{ value, label }`, выбранное значение хранится в
`v-model`. С `clearable` рядом со значением появляется кнопка очистки. Список открывается не уже
самого поля.

## Установка

```ts
import { NuiSelect } from '@numior/vue';
import '@numior/vue/styles/field.css';
import '@numior/vue/styles/list.css';
import '@numior/vue/styles/select.css';
```

## Примеры

### Группы и недоступные варианты

Чтобы разбить варианты на группы, передайте запись `{ label, items }`. Вариант с `disabled`
виден в списке, но выбрать его нельзя, и стрелки его пропускают.

<Example name="select/Groups" />

### Несколько значений

С `multiple` щелчок по варианту отмечает его, и список остаётся открытым. Выбранные значения
хранятся в `v-model:values`. В поле видна подпись варианта, а если их несколько — «Выбрано: 3».

<Example name="select/Multiple" />

### Объекты в значениях

Если значения — объекты, передайте `getKey`: функция возвращает ключ, по которому варианты
отличаются друг от друга. Слот `option` меняет разметку варианта, например добавляет должность
рядом с именем.

<Example name="select/Objects" />

### Дерево

Если у вариантов есть `children`, вместо списка открывается дерево, а ветка с выбранным значением
уже раскрыта. С `multiple` у вариантов появляются флажки, и отметка родителя отмечает всех
потомков.

Ветку с `lazy` вместо `children` дерево загружает при раскрытии: `NuiSelect` шлёт событие
`load`, как [Tree](/components/tree).

<Example name="select/Tree" />

### Размеры

`size` принимает `sm`, `md` и `lg`, как у остальных полей ввода, поэтому поля разных типов в одной
форме совпадают по высоте.

<Example name="select/Sizes" />

## Доступность

Поле — нативная кнопка с ролью `combobox`, а список — `listbox` с вариантами `option`. Диктор
объявляет, открыт ли список, и читает выбранный вариант. Для дерева роли меняются на `tree` и
`treeitem`.

Как у нативного `<select>`, на закрытом поле можно набрать первые буквы варианта, и значение
сменится без открытия списка.
