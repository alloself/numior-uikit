# Dialog

Модальное окно поверх страницы.

<Example name="dialog/Confirm" />

Закройте окно кнопкой формы с `method="dialog"`: её `value` придёт в событии `close`.

## Установка

```ts
import { NuiDialog } from '@numior/vue';
import '@numior/vue/styles/dialog.css';
```

## Использование

Откройте диалог и поменяйте размер, положение и способы закрытия.

<Configurator name="NuiDialog" />

## Примеры

### Потребовать ответа

Отключите `closable`.

<Example name="dialog/Required" />

У окна нет крестика, а Esc и клик по фону его не закрывают.

### Открыть окно из окна

<Example name="dialog/Stacked" />

Фон затемняется один раз, под верхним окном, а Esc закрывает только верхнее окно.

### Поднять окно с формой к верхнему краю

Задайте `placement="top"`.

<Example name="dialog/Placement" />

Окно растёт только вниз и не прыгает, когда поля формы появляются или исчезают.

### Прокрутить длинный текст

<Example name="dialog/Long" />

Прокручивается только текст, а заголовок и кнопки остаются на месте.

## Поведение

Окно остаётся в разметке там, где написано, поэтому тема и направление текста родителя действуют и
на него.

## Доступность

- Экранный диктор при открытии читает заголовок из `title` и описание из `description`.
- Фокус встаёт на первый интерактивный элемент окна, крестик идёт последним. После закрытия фокус
  возвращается на кнопку, которая открыла окно.
- Страница под окном не отвечает на клики и клавиатуру, не прокручивается и не сдвигается вбок.
