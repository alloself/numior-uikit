# Dialog

`NuiDialog` — модальное окно поверх страницы: подтверждение, короткая форма или сообщение, которое
нельзя пропустить. Пока окно открыто, фокус не выходит за его пределы, а страница под ним
недоступна.

<Example name="dialog/Confirm" />

Кнопки в форме с `method="dialog"` закрывают окно без обработчиков, а событие `close` получает
`value` нажатой кнопки: в примере это `cancel` или `confirm`. Окно остаётся в разметке там, где
написано, поэтому тема и направление письма родителя действуют и на него.

## Установка

```ts
import { NuiDialog } from '@numior/vue';
import '@numior/vue/styles/dialog.css';
```

## Примеры

### Обязательный диалог

С `:closable="false"` у окна нет крестика, а Esc и щелчок по фону его не закрывают. Закрыть такое
окно можно только вашей кнопкой, например «Подтверждаю».

<Example name="dialog/Required" />

### Несколько уровней

Диалог, открытый из другого диалога, встаёт поверх него, а затемнение остаётся одно — под верхним
окном. Esc закрывает только верхний диалог, и фокус возвращается на кнопку, которая его открыла.

<Example name="dialog/Stacked" />

### У верхнего края

`placement="top"` ставит окно у верхнего края экрана. Окно с формой тогда не прыгает вверх и вниз,
когда поля появляются или исчезают.

<Example name="dialog/Placement" />

### Длинное содержимое

Длинный текст прокручивается внутри окна, а заголовок и кнопки внизу остаются на месте.

<Example name="dialog/Long" />

## Доступность

Экранный диктор при открытии читает заголовок из `title` и описание из `description`. Первым фокус
получает первый интерактивный элемент в теле окна, крестик стоит в порядке табуляции последним.
Esc закрывает окно и возвращает фокус на кнопку, которая его открыла.

Пока окно открыто, страница под ним не прокручивается и не сдвигается вбок.
