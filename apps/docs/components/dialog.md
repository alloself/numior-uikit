# Dialog

`NuiDialog` — нативный `<dialog>` через `showModal()`: браузер держит фокус внутри, делает фон
инертным, закрывает по Esc и возвращает фокус на кнопку. Элемент остаётся в DOM там, где
написан, поэтому тема и направление письма наследуются без Teleport.

<Example name="dialog/Confirm" />

## Установка

```ts
import { NuiDialog } from '@numior/vue';
import '@numior/vue/styles/dialog.css';
```

## Примеры

### Обязательный диалог

`closable="false"` убирает крест и не даёт закрыть по Esc и клику по фону; закрывает только
ваша кнопка.

<Example name="dialog/Required" />

### Несколько уровней

Диалог поверх диалога встаёт выше в top layer; затемнение всегда одно, под верхним. Esc
закрывает только верхний уровень, фокус возвращается к открывшей его кнопке.

<Example name="dialog/Stacked" />

### У верхнего края

`placement="top"` прижимает диалог к верху экрана: форма не прыгает, когда её высота меняется.

<Example name="dialog/Placement" />

### Длинное содержимое

Длинный текст прокручивается внутри тела диалога, а заголовок и подвал с кнопками остаются на месте.
Полоса прокрутки не выходит за скруглённые углы.

<Example name="dialog/Long" />

## Доступность

`title` и `description` связаны через `aria-labelledby` и `aria-describedby` с id, известными
уже на сервере. Первым фокус получает первый интерактивный элемент тела, кнопка закрытия идёт
последней. Пока диалог открыт, страница не прокручивается, а её ширина не меняется.
