# Splitter

`NuiSplitter` делит область на две панели, а пользователь двигает границу между ними: редактор и
превью, список писем и письмо. Панели кладут в слоты `start` и `end`.

<Example name="splitter/Basic" />

Доля первой панели хранится в `v-model:ratio` числом от 0 до 1, по умолчанию `0.5`. Свойства
`min` и `max` не дают сжать панель сильнее, по умолчанию это `0.1` и `0.9`.

## Установка

```ts
import { NuiSplitter } from '@numior/vue';
import '@numior/vue/styles/splitter.css';
```

## Примеры

### Вертикально

`orientation="vertical"` ставит панели одну над другой. `step` задаёт, на сколько сдвигают
границу стрелки, по умолчанию `0.05`.

<Example name="splitter/Vertical" />

## Поведение

Границу тянут мышью, пером или пальцем. Высоту задайте самому `NuiSplitter` или его родителю:
панели заполняют её целиком, а лишнее содержимое прокручивается внутри панели.

## Доступность

Граница получает фокус по Tab, и диктор называет её положение в процентах. Подпись по умолчанию
— «Изменить размер панелей», своя передаётся в `label`.
