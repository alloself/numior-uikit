# Toggle group

`NuiToggleGroup` — ряд кнопок, из которых нажата одна или несколько. Подходит для выбора вида
(список или сетка), темы оформления, включённых панелей.

<Example name="toggle-group/Basic" />

Кнопки задаются в `items`, а нажатая кнопка приходит в `v-model`. Свойство `required` не даёт
отжать последнюю нажатую кнопку, поэтому значение не становится пустым. Вариант `segmented`
собирает кнопки на общей подложке, вариант по умолчанию `outline` обводит каждую рамкой.

## Установка

```ts
import { NuiToggleGroup } from '@numior/vue';
import '@numior/vue/styles/toggle-group.css';
```

## Примеры

### Несколько нажатых кнопок

С `multiple` можно нажать несколько кнопок, а их значения приходят массивом в `v-model:values`.
Свойство `icon-only` оставляет на кнопках только иконки, а подпись показывается в подсказке и
служит именем кнопки. Кнопку с `disabled` в `items` нажать нельзя.

## Доступность

Без `multiple` группа ведёт себя как набор радиокнопок: корень — `role="radiogroup"`, кнопки —
`role="radio"` с `aria-checked`. С `multiple` корень — `role="group"`, а кнопки получают
`aria-pressed`. Имя группы задаёт `label`.

Tab попадает только на одну кнопку группы, а по остальным ходят стрелки. В вертикальной группе это
стрелки вверх и вниз, при письме справа налево стрелки влево и вправо меняются местами.
