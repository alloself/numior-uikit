# Collapsible

`NuiCollapsible` — секция, которая раскрывается по клику на заголовок: условия доставки, детали
заказа, дополнительные настройки. Несколько таких секций подряд собирает
[Accordion](/components/accordion).

<Example name="collapsible/Basic" />

## Установка

```ts
import { NuiCollapsible } from '@numior/vue';
import '@numior/vue/styles/collapsible.css';
```

## Использование

Текст заголовка передайте в `label`, содержимое — в слот. Свойство `variant="card"` рисует
секцию карточкой с рамкой.

<Configurator name="NuiCollapsible" />

## Примеры

### Свой заголовок

Слот `trigger` заменяет текст заголовка и получает `open`, поэтому подпись может меняться:
«Показать детали» и «Скрыть детали». Через `v-model:open` секцию можно открыть и закрыть из кода.

<Example name="collapsible/Trigger" />

## Поведение

Содержимое раскрывается и сворачивается плавно. Свёрнутый текст остаётся на странице: если найти
его поиском браузера по Ctrl+F, секция раскроется сама.

Свойство `headingLevel` оборачивает заголовок в `<h2>`–`<h6>`, чтобы секция попала в структуру
страницы.

## Доступность

Заголовок — кнопка, и экранный диктор сообщает, раскрыта секция или свёрнута. С `disabled`
кнопка выключается и секцию нельзя переключить.
