# Menu

Выпадающее меню действий по кнопке.

<Example name="menu/Basic" />

Положите кнопку в слот `trigger`, а меню соберите из частей:

- `NuiMenuItem` — пункт с действием;
- `NuiMenuCheckboxItem` — пункт с флажком;
- `NuiMenuRadioGroup` и `NuiMenuRadioItem` — выбор одного варианта из нескольких;
- `NuiMenuSub` — вложенное меню;
- `NuiMenuLabel` — заголовок группы пунктов;
- `NuiMenuSeparator` — линия между группами.

## Установка

```ts install
import { NuiMenu, NuiMenuItem } from '@numior/kit';
```

## Использование

Откройте меню и поменяйте сторону, отступ от кнопки и закрытие после выбора.

## Примеры

### Описать меню массивом

Передайте пункты в `items`.

<Example name="menu/Items" />

Вид пункта задаёт поле `type`:

| `type`              | Пункт и его поля                                                                    |
| ------------------- | ----------------------------------------------------------------------------------- |
| `item` или без поля | Пункт с действием: `label`, `icon`, `shortcut`, `tone`, `href` или `to`, `onSelect` |
| `checkbox`          | Пункт с флажком: `label`, `icon`, `checked`, `onCheckedChange`                      |
| `radio-group`       | Выбор одного варианта: `items`, `value`, `onChange`                                 |
| `sub`               | Вложенное меню: `label`, `icon`, `items`                                            |
| `label`             | Заголовок группы: `label`                                                           |
| `separator`         | Линия между группами, без полей                                                     |

## Поведение

- Меню, открытое с клавиатуры, сразу ставит фокус на первый пункт, а открытое стрелкой вверх —
  на последний.
- После клика фокус стоит на самом меню: стрелка вниз ведёт на первый пункт, стрелка вверх — на
  последний.
- Кольцо фокуса видно у пункта, до которого дошли с клавиатуры. Под мышью пункт только
  подсвечивается.
- Выбор пункта закрывает меню, а `:close-on-select="false"` оставляет его открытым. Пункт с
  флажком меню не закрывает, чтобы можно было отметить несколько.
- Вложенное меню открывается при наведении с небольшой задержкой, а с клавиатуры — по Enter или
  стрелке вправо.
- Клик вне меню закрывает все уровни сразу.

## Доступность

Экранный диктор сообщает, что кнопка открывает меню и открыто ли оно. Пункты с флажком и
переключателем объявляются как отмеченные или нет.

Пункт с `href` или `to` работает как ссылка. Отключённый пункт остаётся в меню, но стрелки его
пропускают и выбрать его нельзя.
