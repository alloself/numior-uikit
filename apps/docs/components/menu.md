# Menu

`NuiMenu` — выпадающее меню действий, которое открывается по кнопке: «Новый документ»,
«Дублировать», «Удалить». Кнопку положите в слот `trigger`, а пункты — внутрь меню.

<Example name="menu/Basic" />

Обычный пункт — `NuiMenuItem`, пункт с флажком — `NuiMenuCheckboxItem`, выбор одного из
вариантов — `NuiMenuRadioGroup` с `NuiMenuRadioItem`. Вложенное меню задаёт `NuiMenuSub`,
заголовок группы — `NuiMenuLabel`, линию между группами — `NuiMenuSeparator`.

## Установка

```ts
import { NuiMenu, NuiMenuItem } from '@numior/vue';
import '@numior/vue/styles/list.css';
import '@numior/vue/styles/menu.css';
```

## Примеры

### Меню из массива

То же меню можно описать массивом `items`. Обычный пункт задаётся записью
`{ label, icon, shortcut, tone, onSelect }`, остальные — записью с полем `type`: `checkbox`,
`radio-group`, `separator`, `label` или `sub`.

## Поведение

Меню открывается щелчком по кнопке. Если его открыли с клавиатуры, фокус сразу встаёт на первый
пункт, а при открытии стрелкой вверх — на последний. При наведении мыши фокус переходит на пункт
под курсором.

После выбора пункта меню закрывается, а `:close-on-select="false"` оставляет его открытым. Пункт
с флажком меню по умолчанию не закрывает, чтобы можно было отметить несколько.

Вложенное меню открывается при наведении с небольшой задержкой, а с клавиатуры — по Enter или
стрелке вправо. Щелчок вне меню закрывает все уровни сразу, а фокус возвращается на кнопку.

## Доступность

Экранный диктор сообщает, что кнопка открывает меню и открыто ли оно. Пункты с флажком и
переключателем объявляются как отмеченные или нет.

Пункт с `href` или `to` работает как ссылка. Отключённый пункт остаётся в меню и получает фокус,
чтобы его можно было прочитать, но выбрать его нельзя.
