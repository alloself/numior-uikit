# Progress

`NuiProgress` — полоса выполнения: загрузка файлов, импорт, готовность задачи. Если результат
нельзя посчитать заранее, полоса показывает, что работа идёт, без процентов.

<Example name="progress/Basic" />

`value` — сколько сделано, `max` — сколько всего, по умолчанию 100. Без `value` по полосе бежит
отрезок. Цвет задаёт `tone`, например `success` или `info`, толщину — `size`: `sm`, `md` или
`lg`.

## Установка

```ts
import { NuiProgress } from '@numior/vue';
import '@numior/vue/styles/progress.css';
```

## Примеры

### Живое значение

Меняйте `value` по ходу работы, и полоса плавно дойдёт до нового значения. Проценты рядом с
полосой выводите обычным текстом, сама полоса их не пишет.

## Доступность

Компонент — нативный `<progress>`, диктор называет его индикатором выполнения и читает значение.
`label` даёт полосе имя, а `valueText` заменяет проценты словами, например «12 из 40 файлов».

Если в системе включено уменьшение анимации, отрезок бежит по полосе вдвое медленнее.
