# Progress

Полоса выполнения задачи.

<Example name="progress/Basic" />

Передайте сделанное в `value` и всё в `max`; без `value` полоса показывает, что срок неизвестен.

## Установка

```ts
import { NuiProgress } from '@numior/vue';
import '@numior/vue/styles/progress.css';
```

## Использование

Поменяйте значение, толщину и тон полосы.

<Configurator name="NuiProgress" />

## Примеры

### Обновлять значение по ходу работы

Меняйте `value`.

<Example name="progress/Live" />

Полоса плавно доходит до нового значения, а текст рядом с ней выводите сами.

## Доступность

Полоса — нативный `<progress>`: экранный диктор называет её индикатором выполнения и читает
значение. `label` даёт полосе имя, а `valueText` заменяет проценты словами, например «340 из 1 200
товаров». Если в системе включено уменьшение анимации, отрезок бежит по полосе вдвое медленнее.
