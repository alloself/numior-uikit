# Pagination

Переключатель страниц длинного списка.

<Example name="pagination/Basic" />

Передайте число записей в `total`; номер и размер страницы хранятся в `v-model:page` и
`v-model:page-size`.

## Установка

```ts
import { NuiPagination } from '@numior/vue';
import '@numior/vue/styles/pagination.css';
```

## Использование

Поменяйте число соседних страниц, крайние кнопки и размер.

<Configurator name="NuiPagination" />

## Примеры

### Сделать страницы ссылками

Передайте функцию `href(page)`.

<Example name="pagination/Links" />

Страницу можно открыть в новой вкладке, а поисковик пройдёт по всем страницам. Для роутера
передайте `RouterLink` или другой компонент ссылки в `as`.

### Уместить в узкий контейнер

<Example name="pagination/Compact" />

Когда компоненту не хватает ширины, номера страниц скрываются, и остаются «назад», «4 / 6» и
«вперёд».

## Поведение

Номер за пределами списка компонент исправляет сам, например когда записей стало меньше.

Когда пользователь меняет размер страницы, первая видимая запись остаётся на экране. Со страницы
5 по 20 записей (81–100) переход на 50 записей ведёт на страницу 2 (51–100).

## Доступность

Компонент — ориентир `<nav>` со списком страниц, текущая страница отмечена
`aria-current="page"`. Экранный диктор называет кнопки «Страница 4» и «Следующая страница», эти
подписи меняются через `pageLabel` и словарь. Недоступные стрелки выключены, при направлении
текста справа налево они смотрят в другую сторону.
