# Pagination

`NuiPagination` — переключатель страниц для длинных таблиц и списков. Он показывает первую и
последнюю страницы, соседей текущей, многоточия между ними и кнопки «назад» и «вперёд».

<Example name="pagination/Basic" />

`total` — общее число записей, а номер и размер страницы хранятся в `v-model:page` и
`v-model:page-size`. Рядом с кнопками выводится строка «21–40 из 240», а с `pageSizes`
появляется выбор числа строк на странице.

## Установка

```ts
import { NuiPagination } from '@numior/vue';
import '@numior/vue/styles/pagination.css';
```

## Примеры

### Ссылки вместо кнопок

Передайте функцию `href(page)`, и страницы станут ссылками: их можно открыть в новой вкладке, а
поисковики пройдут по ним. Свойство `as` подставляет `RouterLink` или другой компонент ссылки.
`edges` добавляет кнопки перехода на первую и последнюю страницы.

<Example name="pagination/Links" />

### Узкий контейнер

Когда компоненту не хватает места, номера страниц скрываются и остаются «назад», «4 / 12» и
«вперёд». Это зависит от ширины самого компонента, а не окна браузера.

## Поведение

`siblings` задаёт, сколько страниц видно по обе стороны от текущей, а `boundaries` — сколько в
начале и в конце; по умолчанию по одной. Номер за пределами списка компонент исправляет сам,
например когда записей стало меньше.

Когда пользователь меняет размер страницы, компонент пересчитывает номер так, чтобы первая
видимая запись осталась на экране. Со страницы 5 по 20 записей (81–100) переход на 50 записей
ведёт на страницу 2 (51–100).

## Доступность

Компонент — ориентир `<nav>` со списком страниц, текущая страница отмечена
`aria-current="page"`. Диктор называет кнопки «Страница 4» и «Следующая страница», эти подписи
меняются через `pageLabel` и словарь. Недоступные стрелки выключены, при письме справа налево
они смотрят в другую сторону.
