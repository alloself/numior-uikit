# Toast

Уведомления показываются императивно: `useToast()` возвращает сервис, а один `<NuiToaster>` на
приложение рендерит очередь. Регион живёт в top layer с `aria-live="polite"`, поэтому
уведомления озвучиваются и остаются над остальными слоями.

## Установка

```ts
import { NuiToaster, useToast } from '@numior/vue';
import '@numior/vue/styles/toast.css';
```

Поставьте один `<NuiToaster />` ближе к концу корневого компонента; на этом сайте он стоит в
раскладке, поэтому примеры вызывают только сервис. Плагин `createNuiConfig` даёт каждому
приложению и SSR-запросу свой store; опции `toasts: { duration, exitDuration, limit }`.

## Примеры

### Замена уведомления

`show` возвращает id; повторный `show` с тем же `id` заменяет уведомление и перезапускает
таймер, так один тост ведёт операцию от начала до результата.

## Поведение

Новое уведомление встаёт у края и становится верхним; предыдущие уходят за него
уменьшенными карточками. Наведение или фокус раскрывает стопку в список, `expand` держит её
раскрытой всегда. Пока стопка под курсором, содержит фокус или вкладка скрыта, таймеры стоят.

Опции `show`: `title`, `description`, `tone`, `duration` (`0` — до закрытия пользователем),
`action` с `label` и `onClick`, `dismissible`, `id`. Уведомление с `tone="error"` получает
`role="alert"`.

## Доступность

Уведомления не забирают фокус при появлении. Esc закрывает сфокусированное уведомление и
переводит фокус на соседнее. Поверх открытого модального диалога уведомление поднимается, но
остаётся инертным до его закрытия.
