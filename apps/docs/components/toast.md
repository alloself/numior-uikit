# Toast

Короткое уведомление о результате действия.

<Example name="toast/Basic" />

Поставьте один `<NuiToaster />` в корневой компонент:

```vue
<template>
  <RouterView />
  <NuiToaster />
</template>
```

Вызывайте уведомления через `useToast()` из любого компонента приложения.

## Установка

```ts
import { NuiToaster } from '@numior/vue';
import { useToast } from '@numior/primitives';
import '@numior/vue/styles/toast.css';
```

## Примеры

### Обновить уведомление на месте

Вызовите `show` с тем же `id`.

<Example name="toast/Update" />

Уведомление меняет текст без повторного появления, и отсчёт времени начинается заново.

### Дать отменить действие

Передайте кнопку в `action`.

<Example name="toast/Undo" />

Клик по кнопке закрывает уведомление, если обработчик не вызвал `show` с тем же `id`.

## Поведение

### Выберите тон

Вызовите метод с именем тона: `success`, `error`, `warning` или `info`.

```ts
const toast = useToast();

toast.error('Оплата не прошла', { description: 'Банк отклонил карту' });
```

Метод `show` принимает тон в опции `tone`, а без неё показывает нейтральное уведомление. Все опции
перечислены на странице [useToast](/composables/toast).

### Настройте место и число уведомлений

Передайте `placement` и `expand` в `<NuiToaster>`, а `duration`, `exitDuration` и `limit` — в
опцию `toasts` плагина `createNuiConfig`:

```ts
app.use(createNuiConfig({ toasts: { duration: 4000, limit: 3 } }));
```

| Опция          | Что меняет                                                         |
| -------------- | ------------------------------------------------------------------ |
| `placement`    | Угол экрана, по умолчанию `top-end`                                |
| `expand`       | Стопка всегда раскрыта списком, а не только при наведении          |
| `duration`     | Время показа в миллисекундах, по умолчанию 5000; `0` — до закрытия |
| `exitDuration` | Длительность исчезновения в миллисекундах, по умолчанию 200        |
| `limit`        | Сколько уведомлений видно сразу, остальные ждут очереди            |

Новое уведомление встаёт впереди, а прежние уходят за него стопкой и раскрываются при наведении или
фокусе. Пока курсор над стопкой, фокус внутри неё или вкладка скрыта, отсчёт времени стоит.

Плагин заводит свою очередь уведомлений для каждого приложения и каждого запроса при SSR.

## Доступность

Экранный диктор зачитывает уведомление, когда закончит текущую фразу, а уведомление с
`tone="error"` получает `role="alert"` и прерывает чтение. Уведомление не забирает фокус, а Esc
закрывает уведомление в фокусе и переводит фокус на соседнее. Уведомления видны поверх диалогов и
меню, но кнопки в них не работают, пока открыт модальный диалог.
