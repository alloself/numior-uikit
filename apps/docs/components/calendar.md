# Calendar

`NuiCalendar` — календарь на странице для выбора одной даты, нескольких дат или диапазона. Для
поля с календарём во всплывающем окне возьмите [Date picker](/components/date-picker).

<Example name="calendar/Basic" />

## Установка

```ts
import { NuiCalendar } from '@numior/vue';
import '@numior/vue/styles/calendar.css';
```

## Примеры

### Несколько дат

С `mode="multiple"` каждый клик добавляет день в выбор или убирает его. В `v-model` лежит массив
дат. Размер `sm` подходит для узких панелей.

<Example name="calendar/Multiple" />

### Диапазон с пресетами

С `mode="range"` первый клик задаёт начало диапазона, второй — конец. Диапазон можно и протянуть
мышью. В `v-model` лежит объект `{ start, end }`.

<Example name="calendar/Range" />

Свойство `presets` добавляет сбоку кнопки готовых диапазонов вроде «Последние 7 дней». Кнопка
диапазона, который сейчас выбран, подсвечивается. Свойство `months` выводит несколько месяцев
рядом.

## Поведение

Даты передаются строками в формате `YYYY-MM-DD`, например `2026-09-27`. Названия месяцев, дней
недели и первый день недели берутся из языка приложения, `locale` и `weekStart` их меняют.

Даты раньше `min`, позже `max` и те, для которых `isDateDisabled` вернула `true`, выбрать нельзя.
Клик по названию месяца или году открывает список месяцев или лет.

Сегодняшний день компонент узнаёт из часов браузера. При серверном рендеринге передайте его в
`today`, иначе он подсветится только после загрузки страницы.

Без `today` и без выбранной даты сервер и браузер рисуют месяц по дате UTC: разметка совпадает
в любом часовом поясе. После загрузки календарь переходит на местную дату. Если страница
отдаётся из кэша дольше суток, передавайте `today` или `month`.

## Доступность

Дни месяца — кнопки, экранный диктор зачитывает у них полную дату: «воскресенье, 27 сентября
2026 г.». Он же сообщает, какие дни выбраны и какой из них сегодня. Между днями переходят
стрелками.
