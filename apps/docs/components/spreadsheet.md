# Книга

Электронная таблица с формулами, которая открывает и сохраняет файлы XLSX.

<Example name="spreadsheet/Basic" />

Создайте книгу через `createWorkbook()`, заполните листы и передайте её в `book`. Правки меняют
эту же книгу, а событие `change` сообщает о каждой из них.

Формулы считает `createCalculator(book)`. Передайте его в `calculator`, если формулы нужно задать
до показа, иначе компонент создаст свой.

## Установка

```ts
import { NuiSpreadsheet } from '@numior/kit/spreadsheet';
```

Модель книги и формулы лежат в `@numior/kit/spreadsheet/core`. Эта точка входа работает без Vue, в
том числе на сервере.

## Примеры

### Только чтение

Запретите правки свойством `readonly`.

<Example name="spreadsheet/ReadOnly" />

Значения остаются доступны для выделения и копирования. Свойства `formulaBar` и `sheetTabs`
убирают строку формул и вкладки.

### Открытие и сохранение XLSX

Покажите панель файла свойством `fileBar`.

<Example name="spreadsheet/File" />

На панели имя файла и кнопки «Открыть» и «Сохранить». Когда файл прочитан, событие `open` передаёт
новую книгу: положите её в `book`.

Без `saveFile` браузер скачает файл. Передайте `saveFile`, чтобы отправить его на сервер.

Части файла, которые компонент не понимает, сохраняются без изменений. Если правка могла их
затронуть, компонент спросит, сохранять ли файл с потерями.

Ячейка файла XLSX вмещает 32 767 символов. Лист хранит более длинный текст целиком. При сохранении
компонент спросит о потере и обрежет такой текст только в файле.

Верните пункты меню ячейки из функции `contextMenu`.

### Совместная работа

`useCollabWorkbook` из `@numior/kit/collaboration/spreadsheet` связывает книгу с сервером.

```vue
<template>
  <NuiCollabFailure v-if="failure !== undefined" :failure="failure" @rejoin="rejoin" />
  <NuiSpreadsheet
    v-if="ready"
    :book="book"
    :calculator="calculator"
    :collaboration="document"
    :readonly="readOnly"
    :peers="peers"
    label="Общая книга"
    @change="sync"
    @presence="sharePlace"
  />
</template>

<script setup lang="ts">
import { webSocketTransport } from '@numior/kit/collaboration';
import { useCollabWorkbook } from '@numior/kit/collaboration/spreadsheet';
import { NuiCollabFailure } from '@numior/kit/collaboration/vue';
import { NuiSpreadsheet } from '@numior/kit/spreadsheet';
import { createCalculator, createWorkbook } from '@numior/kit/spreadsheet/core';

const book = createWorkbook();
const calculator = createCalculator(book);

const { document, ready, readOnly, peers, failure, sync, sharePlace, rejoin } = useCollabWorkbook({
  doc: 'budget',
  user: { id: 'anna', name: 'Анна' },
  transport: webSocketTransport('wss://example.com/collab'),
  book,
  calculator,
});
</script>
```

`sync` из `change` отправляет ваши правки. Правки других людей появляются сами и не вызывают `change`.
`ready` включается, когда книга пришла с сервера, а `sharePlace` показывает остальным, в какой вы ячейке.

Когда другой человек вставляет или удаляет строки и столбцы, активная ячейка и выделение остаются на
своих данных. Открытая ячейка переезжает вместе со строкой: набранный текст, фокус и каретка
сохраняются. Если её строку или столбец удалили, правка закрывается, и лист говорит об этом
заметкой.

Ссылки в недописанной формуле тоже следуют за данными. После вставки строки выше девятой
`=SUM(A3:A9)` становится `=SUM(A3:A10)`, а каретка остаётся у того же символа. Ссылка на удалённые
ячейки становится `#REF!`, как в сохранённой формуле.

Пока в ячейке составляется слово через IME, ячейка и ссылки её формулы ждут. Они переезжают, когда
слово готово, и набор не обрывается.

На экране остаются те же данные: строки, вставленные выше окна, не сдвигают то, что вы читаете.
Если лист прокручен к самому началу, вставленные в начало строки видны сразу.

Правила условного форматирования, которые разные люди добавили одновременно, остаются все. Порядок
правил задаёт тот, кто его менял.

Когда связь ломается, правки больше не отправляются: `readOnly` включается, а `failure` несёт
причину. `NuiCollabFailure` объясняет её и предлагает открыть книгу заново — это вызов `rejoin`.
Страница не перезагружается.

Сервер пришлёт книгу целиком. Она заменит локальную вместе с неотправленными правками, а лист
останется на той же вкладке. Пока книга не пришла, лист открыт только для чтения.

Панель `fileBar` в общей книге не показывайте: открытие файла заменяет книгу, и участники перестанут
её видеть. Запрет правок задаёт свойство `readonly`.

## Поведение

### Формулы

Ввод, начатый с `=`, становится формулой. Пока курсор стоит на месте операнда, клик, протяжка или
стрелки подставляют ссылку, а `F4` перебирает знаки `$`.

Ссылки в тексте формулы и рамки диапазонов на листе окрашены одинаково. Рамку можно потянуть за
край или угол, и ссылка в формуле изменится. После букв появляется список функций, а внутри скобок
подсказка показывает текущий аргумент.

Ссылки соединяются операторами Excel. Двоеточие строит прямоугольник от двух ссылок
(`A1:ИНДЕКС(A:A;5)`), а пробел даёт их пересечение (`A1:C3 B2:D4`). Список в скобках собирает
несколько областей (`СУММ((A1;C1:C3))`).

Области читают те функции, которым их даёт Excel, — `СУММ`, `СЧЁТ`, `ИНДЕКС`, `ОБЛАСТИ` и другие;
остальные отвечают `#ЗНАЧ!`.

На большой книге пересчёт идёт частями. Значения, которые ещё считаются, отмечены, а внизу виден
ход пересчёта с кнопкой остановки.

### Выделение и заполнение

Маркер в углу выделения продолжает ряд чисел или копирует формулы со сдвигом ссылок. Протяжка
маркера назад очищает ячейки.

В меню ячейки находятся вставка и удаление строк и колонок, объединение ячеек, условное
форматирование, сводные таблицы, диаграммы и картинки. На вкладках листы добавляют, переименовывают
и удаляют.

### Объединение ячеек

Пункт «Объединить ячейки» в меню ячейки делает из выделенного диапазона одну ячейку. Каждый
выделенный диапазон объединяется отдельно, а объединения внутри него заменяются новым.

В объединённой ячейке остаётся значение первой заполненной ячейки диапазона, считая по строкам.
Остальные значения удаляются, и лист говорит об этом заметкой. `Ctrl+Z` возвращает ячейки и их
значения одним шагом.

Пункт «Разъединить ячейки» разбирает объединения, которые задевает выделение. Значение остаётся в
первой ячейке. Целые строки и колонки не объединяются, а в таблице и в сводной таблице лист
отвечает отказом с причиной `merge-blocked`.

Своя панель инструментов вызывает те же действия методами `mergeCells()` и `unmergeCells()`.

### Ширина колонок и высота строк

Колонку расширяют за правый край заголовка, строку — за нижний край её номера. С клавиатуры размер
меняют `Alt` со стрелкой на заголовке колонки или на номере строки.

Двойной клик по краю заголовка колонки подбирает ширину по самому длинному тексту её ячеек, пустая
колонка возвращается к ширине листа. Двойной клик по краю номера строки возвращает высоту по
умолчанию.

Подбор читает ячейки на экране и первые ячейки сверху, всего до 10 000 на жест. Если ячеек в
колонке больше, лист говорит об этом заметкой. Скрытые строки и ячейки, объединённые через несколько
колонок, в счёт не идут.

Размер хранится в книге по листам: его отменяет `Ctrl+Z`, он попадает в XLSX и виден соавторам.
Шаг книги пишется один раз, в конце жеста.

Когда выделено несколько строк или колонок целиком, край одной из них задаёт размер всем
выделенным, а двойной клик подбирает ширину каждой выделенной колонке. Если выделен весь лист, меняется размер по умолчанию, а свои размеры линий
сбрасываются. Больше 20 000 строк за один жест лист не меняет и отвечает отказом с причиной
`lines-too-many`.

В книге только для чтения размер меняется лишь на экране, пока показан этот лист.

### Рисунки и диаграммы

Рисунок выбирают кликом, а с клавиатуры — `Alt+F10` из ячейки. `Tab` переходит к следующему
рисунку. Выбранный рисунок двигают стрелками и удаляют клавишей `Delete`.

У рисунка своё меню: правый клик, долгое нажатие на телефоне или `Shift+F10` у выбранного
рисунка. В меню есть «Удалить», а у диаграммы ещё «Настройки диаграммы». В книге только для чтения
меню рисунка нет.

### Отказ действия

Действие, которое лист не выполнил, объясняется заметкой в нижнем углу листа. Так лист отвечает на
заполнение через объединённые ячейки, объединение ячеек таблицы, правку ячейки сводной таблицы и
вставку строки сверх предела.
Заметкой с причиной `cell-gone` лист сообщает и о правке, чью ячейку удалил другой участник.

Заметка гаснет через шесть секунд, после следующей удачной правки или по клику. Пока указатель над
ней, она остаётся на месте. Тот же текст получает живой регион.

Событие `refuse` передаёт `{ reason, message }`. Причины перечислены в `NuiSpreadsheetRefusalReason`:
по ним приложение показывает своё сообщение или ведёт журнал.

## Доступность

Лист размечен как `role="grid"`. Tab попадает в таблицу один раз, а по ячейкам фокус ходит
стрелками. Строка формул связана с активной ячейкой, а итог правок объявляется живым регионом.

На телефоне двойное касание открывает правку, а долгое нажатие — меню ячейки или рисунка.
