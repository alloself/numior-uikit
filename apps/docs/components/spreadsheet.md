# Spreadsheet

`NuiSpreadsheet` — электронная таблица с формулами, вкладками листов и работой с файлами XLSX.
Берите её, когда пользователю нужны вычисления прямо на странице.

<Example name="spreadsheet/Basic" />

Создайте книгу через `createWorkbook()`, заполните листы и передайте её в `book`. Правки меняют
эту же книгу, а событие `change` сообщает о каждой из них.

Формулы считает `createCalculator(book)`. Передайте его в `calculator`, если формулы нужно задать
до показа, иначе компонент создаст свой.

## Установка

```ts
import { NuiSpreadsheet } from '@numior/spreadsheet';
import '@numior/vue/styles.css';
import '@numior/table/styles.css';
import '@numior/spreadsheet/styles.css';
```

Модель книги и формулы лежат в `@numior/spreadsheet/core`. Эта точка входа работает без Vue, в
том числе на сервере.

## Примеры

### Только чтение

Свойство `readonly` запрещает правки, а значения остаются доступны для выделения и копирования.
Свойства `formulaBar` и `sheetTabs` убирают строку формул и вкладки.

<Example name="spreadsheet/ReadOnly" />

### Открытие и сохранение XLSX

Свойство `fileBar` показывает панель с именем файла и кнопками «Открыть» и «Сохранить». Когда файл
прочитан, событие `open` передаёт новую книгу: положите её в `book`.

Без `saveFile` браузер скачает файл. Передайте `saveFile`, чтобы отправить его на сервер.

<Example name="spreadsheet/File" />

Части файла, которые компонент не понимает, сохраняются без изменений. Если правка могла их
затронуть, компонент спросит, сохранять ли файл с потерями.

### Свои пункты меню

Функция `contextMenu` получает лист и выделение и возвращает пункты, которые появятся в меню
ячейки.

<Example name="spreadsheet/Menu" />

### Совместная правка

Создайте документ через `createWorkbookDocument` и передайте его в `collaboration`. Клиент
`createCollabClient` из `@numior/collaboration` связывает документ с сервером.

```vue
<template>
  <NuiSpreadsheet
    v-if="ready"
    :book="book"
    :calculator="calculator"
    :collaboration="document"
    label="Общая книга"
    @change="client.sync()"
  />
</template>
```

Вызывайте `client.sync()` из `change`, чтобы отправить свои правки. Правки других людей появляются
сами и не вызывают `change`. Показывайте таблицу после загрузки книги с сервера.

Панель `fileBar` в общей книге не показывайте: открытие файла заменяет книгу, и участники перестанут
её видеть. Запрет правок задаёт свойство `readonly`.

## Поведение

### Формулы

Ввод, начатый с `=`, становится формулой. Пока курсор стоит на месте операнда, щелчок, протяжка или
стрелки подставляют ссылку, а `F4` перебирает знаки `$`.

Ссылки в тексте формулы и рамки диапазонов на листе окрашены одинаково. Рамку можно потянуть за
край или угол, и ссылка в формуле изменится. После букв появляется список функций, а внутри скобок
подсказка показывает текущий аргумент.

На большой книге пересчёт идёт частями. Значения, которые ещё считаются, отмечены, а внизу виден
ход пересчёта с кнопкой остановки.

### Выделение и заполнение

Маркер в углу выделения продолжает ряд чисел или копирует формулы со сдвигом ссылок. Протяжка
маркера назад очищает ячейки.

В меню ячейки находятся вставка и удаление строк и колонок, условное форматирование, сводные
таблицы, диаграммы и картинки. На вкладках листы добавляют, переименовывают и удаляют.

### Ширина колонок

Колонку расширяют за правый край заголовка или клавишами `Alt` со стрелкой на заголовке. Ширина
хранится в книге по листам: её отменяет `Ctrl+Z`, она попадает в XLSX и видна соавторам. Двойной
щелчок по краю возвращает ширину по умолчанию.

В книге только для чтения ширина меняется лишь на экране, пока показан этот лист.

## Доступность

Лист размечен как `role="grid"`. Tab попадает в таблицу один раз, а по ячейкам фокус ходит
стрелками. Строка формул связана с активной ячейкой, а итог правок объявляется живым регионом.

На телефоне двойное касание открывает правку, а долгое нажатие — меню ячейки.
