# Tooltip

`NuiTooltip` — подсказка с `role="tooltip"`, связанная с триггером через `aria-describedby`.
Она показывается при наведении с задержкой и сразу при фокусе. Скрывается при уходе курсора,
потере фокуса и по Esc; на саму подсказку можно навести курсор, не закрыв её.

<Example name="tooltip/Basic" />

## Установка

```ts
import { NuiTooltip } from '@numior/vue';
import '@numior/vue/styles/tooltip.css';
```

## Примеры

### Кнопка с иконкой

Подсказка описывает триггер, а не заменяет его имя: кнопке без текста всё равно нужен
`aria-label`.

<Example name="tooltip/IconButton" />

## Доступность

Поведение соответствует WCAG 1.4.13: закрывается по Esc, остаётся при наведении на неё, не
исчезает сама. На сенсорных экранах подсказка не показывается, поэтому её текст не должен быть
единственным источником информации.
