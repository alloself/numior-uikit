# Tooltip

`NuiTooltip` — всплывающая подсказка с коротким пояснением к кнопке или другому элементу. Она
появляется при наведении курсора и при фокусе с клавиатуры.

<Example name="tooltip/Basic" />

Элемент, к которому относится подсказка, кладётся в слот `trigger` и получает из него `attrs`:
обработчики и `aria-describedby`. Подсказка появляется через 300 мс после наведения, при фокусе —
сразу. Задержку меняет `openDelay`, а сторону — `placement`, по умолчанию `top`.

## Установка

```ts
import { NuiTooltip } from '@numior/vue';
import '@numior/vue/styles/tooltip.css';
```

## Примеры

### Кнопка с иконкой

Подсказка дополняет имя кнопки, но не заменяет его, поэтому кнопке из одной иконки всё равно
нужен `aria-label`.

## Доступность

Подсказка следует WCAG 1.4.13: её закрывает Esc, на неё можно навести курсор, и она не исчезает
сама по таймеру. Она скрывается, когда курсор уходит или элемент теряет фокус.

Экранный диктор читает текст подсказки как описание элемента через `aria-describedby`. На
сенсорных экранах подсказка не появляется, поэтому не кладите в неё то, без чего интерфейс не
понять.
