# Tooltip

Короткая подсказка к кнопке или значку.

<Example name="tooltip/Basic" />

Кнопку положите в слот `trigger` и передайте ей `attrs`, как у [Popover](/components/popover).

## Установка

```ts install
import { NuiTooltip } from '@numior/vue';
```

## Использование

Наведите курсор на кнопку и поменяйте сторону подсказки, отступ и задержки.

<Configurator name="NuiTooltip" />

## Примеры

### Подписать кнопку с иконкой

Оставьте кнопке `aria-label`: подсказка дополняет имя, а не заменяет его.

<Example name="tooltip/IconButton" />

### Показать сочетание клавиш

Задайте `shortcut` и подключите `@numior/vue/styles/kbd.css`.

<Example name="tooltip/Shortcut" />

Сочетание записывается как у [Kbd](/components/kbd): `mod+shift+c` на Mac выглядит как ⇧ ⌘ C, а в
Windows как Ctrl Shift C. Подсказке с целями в `anchor` передайте функцию: она получает элемент под
курсором и возвращает его сочетание.

### Показать обрезанный текст целиком

Передайте в `anchor` функцию `when`: подсказка откроется только над теми целями, для которых она
вернёт `true`.

<Example name="tooltip/Clipped" />

## Доступность

Подсказка следует WCAG 1.4.13:

- Esc её закрывает;
- на неё можно навести курсор, и она не пропадёт;
- она не исчезает сама по таймеру, а скрывается, когда курсор уходит или кнопка теряет фокус.

Экранный диктор читает текст подсказки как описание кнопки через `aria-describedby`. На сенсорных
экранах подсказка не появляется, поэтому не кладите в неё то, без чего интерфейс не понять.
