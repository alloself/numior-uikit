# Файлы и ссылки

Картинки, файлы, видео и карточки ссылок вставляются прямо в документ.

<Example name="editor/Uploads" />

Без `upload` картинку и файл можно вставить только ссылкой.

Файл попадает в документ из меню «/», кнопки «+», буфера обмена или перетаскиванием. Пока он
загружается, на его месте стоит карточка с ходом загрузки, отменой и повтором. Файл не по
`accept` или больше `maxSize` не загружается: его карточка называет причину, пока её не уберут.

Адаптер получает файл, сообщает долю загрузки в `onProgress` и возвращает адрес файла. Отмена
загрузки прерывает `signal`.

## Картинка в тексте

Картинка стоит в строке текста. В её панели выбирается обтекание: в тексте, с обтеканием или
отдельной строкой, а также выравнивание по краю или по центру.

Ширину меняют, потянув за угол, или стрелками, когда угол в фокусе. Описание для экранного диктора
и подпись под картинкой задаются в той же панели.

## Встроить видео

Перечислите в `embeds` сервисы, которые можно встраивать.

<Example name="editor/Embeds" />

Готовы правила для `youtube`, `vimeo`, `loom`, `figma`, `maps` и `codepen`. Свой сервис
описывается объектом `{ id, label, aspect, source }`, где `source(url)` возвращает адрес окна.

Голая ссылка, вставленная в пустую строку, открывает меню: встроить её, показать закладкой или
оставить ссылкой. Ссылки на сервисы не из списка встраиваться не будут.
