# Редактор

Редактор текста с блоками, таблицами и файлами, который хранит документ в HTML или JSON.

<Example name="editor/Basic" />

Наберите `/` в начале строки или нажмите «+» в панели, чтобы вставить блок.

## Установка

```ts install:packages
import { NuiEditor } from '@numior/editor-vue';
import type { DocJSON } from '@numior/editor-core';
```

`@numior/editor-core` хранит модель документа: тип `DocJSON` и функции вроде `fromHTML`. Текст
документа оформляют стили `@numior/content`, а таблицу внутри документа — стили `@numior/table`.

## Сохранить документ

По умолчанию `v-model` хранит строку HTML. Задайте `format="json"`, чтобы хранить документ
объектом.

<Example name="editor/Json" />

JSON можно сразу положить в базу и вывести на сайте через [`NuiContent`](/editor/content), не
разбирая HTML. Когда редактор теряет фокус или форма отправляется, модель обновляется без
задержки, так что ждать перед сохранением не нужно.

## Выбрать панель

Задайте `toolbar`, чтобы выбрать, где стоит панель форматирования.

<Example name="editor/Toolbar" />

Тип блока выбирается в панели у выделения. В верхней панели он есть в режиме `fixed`, а в режиме
`both` — на сенсорных экранах, где панели у выделения нет.

На телефоне верхняя панель встаёт над клавиатурой и получает кнопки сдвига пункта списка.

## Упомянуть сотрудника

Передайте функцию поиска в `mentions`.

<Example name="editor/Mentions" />

Символ `@` открывает список у курсора. Редактор ждёт паузы в наборе и отменяет прежний запрос
через `signal`, поэтому функция может сразу обращаться к серверу.

## Markdown при вводе

Привычная разметка Markdown превращается в блоки и стили прямо при наборе:

| Наберите                 | Получится                                                      |
| ------------------------ | -------------------------------------------------------------- |
| `#` … `######` и пробел  | Заголовок первого–шестого уровня                               |
| `>` и пробел             | Цитата                                                         |
| `-` или `*` и пробел     | Маркированный список                                           |
| `1.` и пробел            | Нумерованный список, который начинается с этого числа          |
| `[ ]` или `[x]` и пробел | Список задач с пустым или отмеченным пунктом                   |
| ` ``` ` и пробел         | Блок кода; язык пишется сразу за кавычками, например ` ```ts ` |
| `---`                    | Разделитель                                                    |
| `**жирный**`             | **жирный**                                                     |
| `*курсив*`               | _курсив_                                                       |
| `` `код` ``              | `код`                                                          |
| `~~зачёркнутый~~`        | ~~зачёркнутый~~                                                |

Правила блоков срабатывают в начале строки. Backspace сразу после замены возвращает набранные
символы.

## Только чтение

Задайте `readonly`, чтобы показать документ без правки: текст можно выделить и скопировать.
Опубликованный документ выводите через [`NuiContent`](/editor/content): на странице сайта код
редактора не нужен.

## Управлять из кода

Получите ссылку на компонент через `useTemplateRef`, и в поле `editor` будут методы редактора:

```vue
<template>
  <NuiEditor ref="description" v-model="text" label="Описание товара" />
  <NuiButton @click="save">Сохранить</NuiButton>
</template>

<script setup lang="ts">
import { ref, useTemplateRef } from 'vue';
import { NuiEditor } from '@numior/editor-vue';
import { NuiButton } from '@numior/vue';

const text = ref('');
const saved = ref('');
const description = useTemplateRef('description');

const save = () => {
  description.value?.editor.flush();
  saved.value = text.value;
};
</script>
```

`flush()` записывает правки в `v-model`, не дожидаясь паузы в наборе. `focus()` ставит курсор в
текст, а `run()` выполняет команду из `@numior/editor-core`. Остальные методы отдают координаты для
своего слоя поверх текста в слоте `overlay`.

## Доступность

Область текста — многострочное поле, которое экранный диктор называет по `label` или
`aria-label`. В меню «/» и «@» фокус остаётся в тексте, а диктор читает выбранный вариант. Итог
загрузки файла и причина отказа объявляются вслух.

Панель форматирования занимает одну точку табуляции, а по её кнопкам ходят стрелки. Пункт списка
задач читается как флажок с текстом пункта.

<KeyboardReference name="NuiEditor" />

На Mac сочетания с Ctrl набираются с ⌘.

На сервере редактор выводит документ без правки, а после монтирования в браузере текст становится
редактируемым.
