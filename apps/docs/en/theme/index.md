# Theme builder

Pick a preset, a color, a radius and a font. The preview shows the components in this theme, and “Theme code” gives you the Tailwind entry with its keys.

<ThemeBuilder />

How the theme keys work and how to apply a theme to part of a page is covered in [Custom theme](/en/guide/custom-theme). Every key with a sample is listed in [Tokens](/en/theme/tokens).
