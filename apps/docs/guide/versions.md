# Версии

Как нумеруются релизы и что меняется от версии к версии.

## Одна версия на все пакеты

У всех пакетов `@numior/*` один номер версии. Ставьте их одной версии, чтобы компоненты, формы и
таблица подходили друг другу:

```json
{
  "dependencies": {
    "@numior/vue": "1.4.0",
    "@numior/forms": "1.4.0",
    "@numior/table": "1.4.0"
  }
}
```

Vue остаётся зависимостью вашего приложения: пакетам нужна версия 3.5 или новее.

## Что означает номер

Номер версии следует SemVer:

| Часть номера    | Что меняется                                | Что делать                       |
| --------------- | ------------------------------------------- | -------------------------------- |
| Третья, `1.4.1` | Исправления ошибок                          | Обновляйтесь без правок кода     |
| Вторая, `1.5.0` | Новые компоненты, свойства и слоты          | Обновляйтесь без правок кода     |
| Первая, `2.0.0` | Удаление или смена свойств, событий, слотов | Пройдите руководство по переходу |

Ломающие изменения выходят только в новой первой цифре. К каждой такой версии прилагается
руководство по переходу со списком правок.

## Поддержка прошлой версии

После выхода новой старшей версии прошлая ещё шесть месяцев получает исправления безопасности и
критических ошибок. Новые возможности в неё не добавляются.
