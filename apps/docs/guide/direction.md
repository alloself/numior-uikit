# Направление письма

Как вывести интерфейс справа налево для арабского, иврита и других RTL-языков.

<Example name="guide/Direction" />

Поставьте атрибут `dir="rtl"` на `<html>` или на элемент, внутри которого нужен RTL. Текст в
полях прижмётся вправо, шевроны и стрелки пагинации развернутся, а ArrowLeft и ArrowRight
поменяются местами.

## Направление в настройках

Передайте `dir` в `createNuiConfig` или `provideNuiConfig`, если направление переключается на
лету или страница рендерится на сервере:

```ts
createNuiConfig({ dir: () => (settings.rtl ? 'rtl' : 'ltr') });
```

Если `dir` в настройках не задан, компонент берёт ближайший атрибут `dir` над собой, затем
атрибут документа. Если атрибута нет нигде, направление — `ltr`.

## Что разворачивается

- Отступы, рамки и позиции, заданные логическими свойствами: `margin-inline-start`,
  `inset-inline-end`, `border-inline-start`.
- Выравнивание поповеров и меню по началу и концу, например `bottom-start`.
- Клавиши ArrowLeft и ArrowRight в списках, вкладках, дереве и разделителе.

Поля времени и чисел остаются слева направо: цифры так пишут и в RTL-текстах.

## Свой компонент

В своих компонентах берите направление из `useDirection`, а не из `getComputedStyle`. На
сервере `useDirection` возвращает значение из настроек:

```ts
import { useDirection } from '@numior/vue';

const direction = useDirection(root);
const shift = computed(() => (direction.isRtl() ? -offset.value : offset.value));
```

`isRtl()` и `dir()` — функции. Вызывайте их внутри `computed`, чтобы значение обновлялось при
смене настроек.
