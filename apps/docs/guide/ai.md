# ИИ-ассистенты

Как дать ассистенту документацию Numior UI в виде, который он читает без потерь.

## Страница в Markdown

У каждой страницы есть копия в Markdown: добавьте `.md` к её адресу. Примеры в копии идут
кодом, а справочник API — таблицами.

```text
/components/button.md
```

## Каталог llms.txt

Файл `/llms.txt` перечисляет все страницы со ссылками на их копии в Markdown. Формат описан на
[llmstxt.org](https://llmstxt.org). Ассистенты и редакторы кода находят по нему нужную страницу.

| Файл                | Что внутри                                  |
| ------------------- | ------------------------------------------- |
| `/llms-ru.txt`      | Список страниц на русском                   |
| `/llms-full-ru.txt` | Вся документация на русском одним файлом    |
| `/llms.txt`         | Список страниц на английском                |
| `/llms-full.txt`    | Вся документация на английском одним файлом |

## Сервер MCP

Пакет `@numior/mcp` — сервер [MCP](https://modelcontextprotocol.io) для Claude Code, Cursor и
других клиентов. Он отдаёт ассистенту справочник компонентов, страницы документации и примеры,
а ещё проверяет код на ошибки в использовании Numior UI. Документация лежит внутри пакета,
поэтому сервер работает без сети.

### Установите сервер

Добавьте пакет в зависимости разработки:

::: code-group

```sh [pnpm]
pnpm add -D @numior/mcp
```

```sh [npm]
npm install -D @numior/mcp
```

```sh [yarn]
yarn add -D @numior/mcp
```

```sh [bun]
bun add -d @numior/mcp
```

:::

Клиент запускает сервер командой `npx -y @numior/mcp` и обменивается с ним сообщениями через
стандартный ввод и вывод. Версия сервера совпадает с версией остальных пакетов `@numior/*`.

### Подключите Claude Code

Зарегистрируйте сервер в корне проекта:

```sh
claude mcp add numior -- npx -y @numior/mcp
```

С флагом `--scope project` перед именем сервера настройка попадёт в `.mcp.json`. Тогда сервер
появится у всех, кто работает с репозиторием.

### Подключите Cursor

Добавьте сервер в `.cursor/mcp.json` в корне проекта:

```json
{
  "mcpServers": {
    "numior": {
      "command": "npx",
      "args": ["-y", "@numior/mcp"]
    }
  }
}
```

Другие клиенты MCP запускают сервер той же командой.

### Инструменты

| Инструмент        | Что возвращает                                                                      |
| ----------------- | ----------------------------------------------------------------------------------- |
| `list_components` | Компоненты с пакетом, страницей и описанием; фильтр по пакету                       |
| `get_component`   | Свойства, модели, события, слоты, клавиши и файлы стилей компонента, копию страницы |
| `get_example`     | Файлы примера из документации по имени, например `select/Basic`                     |
| `get_page`        | Копию страницы в Markdown по адресу, например `/guide/theming`                      |
| `search`          | Страницы по словам из заголовков, описаний и текста, лучшие совпадения первыми      |
| `list_tokens`     | Токены темы со значениями для светлой и тёмной темы; фильтр по группе               |
| `list_icons`      | Имена иконок; фильтр по строке                                                      |
| `check_usage`     | Ошибки в коде SFC с номером строки и подсказкой                                     |

Инструменты с текстом принимают `locale`: `en` по умолчанию или `ru`.

### Проверьте код

Попросите ассистента вызывать `check_usage` для каждого компонента, который он написал.
Инструмент находит неизвестные компоненты, свойства и события, значения не из списка и импорт
имени, которого нет в пакете. Ещё он предупреждает о неподключённых стилях и о селекторах,
которые меняют вид компонентов Numior UI снаружи.

```vue
<NuiButton variant="primary">Сохранить</NuiButton>
```

У каждой находки есть номер строки и подсказка:

```json
{
  "line": 2,
  "severity": "error",
  "code": "invalid-value",
  "message": "`NuiButton` не принимает `variant=\"primary\"`.",
  "hint": "Допустимые значения: `solid`, `soft`, `outline`, `ghost`, `plain`, `link`. `primary` — значение свойства `tone`."
}
```

Предупреждение о стилях можно не учитывать, если их подключает точка входа приложения.
