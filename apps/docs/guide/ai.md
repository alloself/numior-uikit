# ИИ-ассистенты

Как дать ассистенту документацию Numior UI в виде, который он читает без потерь.

## Страница в Markdown

У каждой страницы есть копия в Markdown: добавьте `.md` к её адресу. Примеры в копии идут
кодом, а справочник API — таблицами.

```text
/components/button.md
```

Кнопка «Скопировать страницу» рядом с заголовком кладёт эту копию в буфер обмена. Вставьте её в
чат с ассистентом вместе с вопросом.

## Каталог llms.txt

Файл `/llms.txt` перечисляет все страницы со ссылками на их копии в Markdown. Формат описан на
[llmstxt.org](https://llmstxt.org). Ассистенты и редакторы кода находят по нему нужную страницу.

| Файл                | Что внутри                                  |
| ------------------- | ------------------------------------------- |
| `/llms-ru.txt`      | Список страниц на русском                   |
| `/llms-full-ru.txt` | Вся документация на русском одним файлом    |
| `/llms.txt`         | Список страниц на английском                |
| `/llms-full.txt`    | Вся документация на английском одним файлом |
