# Браузеры

Какие браузеры поддерживаются и на какие возможности платформы опираются компоненты.

## Поддерживаемые версии

Компоненты работают в двух последних стабильных версиях каждого браузера:

| Браузер       | Где                            |
| ------------- | ------------------------------ |
| Chrome и Edge | Windows, macOS, Linux, Android |
| Firefox       | Windows, macOS, Linux          |
| Safari        | macOS и iOS                    |

Каждое изменение проверяется в Chromium, Firefox и WebKit, а также в профилях телефонов на
Android и iOS.

## На что опираются компоненты

Диалоги, поповеры и темы построены на возможностях браузера, а не на собственных заменах:

- `<dialog>` и Popover API открывают окна и меню в верхнем слое страницы.
- `@starting-style` и `transition-behavior: allow-discrete` анимируют появление и закрытие.
- `light-dark()`, `color-mix()` и относительные цвета `oklab(from …)` считают цвета тем.
- `:dir()` и логические свойства разворачивают интерфейс для письма справа налево.
- `:has()` и контейнерные запросы меняют раскладку без кода на JavaScript.

Полифилов в пакетах нет. Если вашей аудитории нужны более старые версии, проверьте в них
компоненты, которые используете.

Сборка тоже не должна подменять эти функции. Vite с целями по умолчанию переписывает
`light-dark()` при минификации CSS, и вложенная область схемы перестаёт менять цвета. Задайте
цели с поддержкой функций:

```ts
export default defineConfig({
  build: { cssTarget: ['chrome123', 'firefox125', 'safari17.5'] },
});
```

## Сервер

Компоненты рендерятся на сервере без DOM и гидрируются без расхождений в разметке. Что передать
с сервера, описано в руководстве [SSR и Nuxt](/guide/ssr).
