# useMediaQuery

`useMediaQuery(query)` возвращает ref с результатом медиазапроса. До монтирования и на
сервере значение `false`, поэтому серверная разметка и первый кадр совпадают, а после
монтирования ref следует за `matchMedia`.

## Поведение

Запрос принимает строку, ref или геттер; смена запроса переподписывает слушатель. `NuiLayout`
так узнаёт узкий экран: до монтирования он считает экран широким и не мигает боковой панелью.
