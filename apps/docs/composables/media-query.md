# useMediaQuery

`useMediaQuery(query)` возвращает ref, который равен `true`, пока выполняется медиазапрос,
например `'(max-width: 768px)'`. До монтирования и на сервере значение — `false`, поэтому
разметка с сервера совпадает с первым кадром в браузере.

## Поведение

`query` принимает строку, ref или геттер. Когда запрос меняется, композабл следит уже за новым.

Так `NuiLayout` узнаёт, что экран узкий. До монтирования он считает экран широким, и боковая
панель не мигает.
