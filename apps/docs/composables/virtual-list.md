# useVirtualList

`useVirtualList(container, options)` рендерит только видимые строки длинного списка: по
`count` и `itemSize` считает диапазон, отступы до и после него и общий размер. Контейнер
остаётся вашим, поэтому строки можно класть в `<tbody>` или любой список.

## Поведение

`items` — видимые элементы с индексом, началом и размером, `startSize` и `endSize` —
отступы-заполнители, `totalSize` — полная высота. На сервере рендерятся первые `initialCount`
строк, `pinned` держит индекс в окне при изменении данных, `scrollTo(index)` прокручивает к
строке. `overscan` добавляет строки за краями окна.

У каждого элемента есть `slot` — небольшое число, которое остаётся за строкой, пока она
отрисована. Когда строка уходит из окна, слот переходит к новой. Ключуйте строки по `slot`,
и браузер будет патчить те же элементы, а не монтировать новые на каждом шаге прокрутки.

Браузер прокручивает на потоке композитора, а строки рисует главный поток на кадр позже.
Если обновление не успело к кадру, строки на высоком холсте при быстрой протяжке ползунка
уезжают из viewport.

Держите строки в окне с `position: sticky` размером во viewport. Блок подряд идущих строк
двигайте через `translate: 0 <windowOffset>px`, где `windowOffset` — смещение первой
отрисованной строки относительно viewport. Строки на координатах холста двигайте через
`translate: 0 -<scrollTop>px`.

Композитор держит липкое окно на месте, пока следующий кадр не заменит его строки.

`listen: false` оставляет событие скролла вам. Вызывайте `measure()` из одного общего
обработчика, когда несколько окон делят один скроллер, чтобы строки обновлялись раз за событие.

`axis: 'x'` считает окно по горизонтали по `scrollLeft` и ширине; в RTL прокрутка идёт от
правого края. `maxSize` держит холст ниже потолка браузера. Тогда `canvasSize` — физическая
высота, `scrollTop` — логическая, а `items[].offset` даёт позицию строки внутри холста.

`createSizeIndex(count, estimate)` хранит измеренные размеры в дереве Фенвика. Передайте его как
`itemSize` и после измерения строки вызовите `set(index, size)`.
