# useScrollSpy

`useScrollSpy(ids, options)` следит, какой раздел страницы сейчас читают. Используйте его,
чтобы подсветить текущий пункт оглавления.

Текущим считается последний заголовок, чей верх поднялся выше линии `line`. Линия задаётся
долей высоты окна или контейнера `root`, по умолчанию 0.2, то есть пятая часть сверху.

## Поведение

`activeId` — id текущего заголовка. `activate(id)` сразу делает раздел текущим и держит его,
пока прокрутка не закончится. Поэтому после клика по пункту оглавления подсветка не
перескакивает на соседний заголовок.

Вызовите `measure()`, если содержимое страницы изменилось. На этом композабле работает
[Toc](/components/toc).
